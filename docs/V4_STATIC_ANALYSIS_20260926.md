- 【静态】重放失败后 `joint.m:83-86` 转恢复，但恢复只最小化内部打靶模型残差；模型本来接近可行，预测下降立即不大于 0，判为停滞。能暴露真实残差的重建分支（`joint.m:78`）要求模型残差低于 `restore_tolerance=1e-8`，恰在求解器精度底线；run 04 的 108 个恢复状态重建次数全部为 0。

- 口径更正：实现把所有残差按 L≈6978 km 缩放（实施记录中的 SCvx 无量纲化），不是规格 6.1 节的 κr=1 km。在该缩放下，偏心率原值与位置残差在几何上一致（Δe=0.001 约相当于 7 km），因此“偏心率未按规格缩放”不单独构成缺陷；问题在于零余量。
