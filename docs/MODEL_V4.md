# CTOC14 V4：以完整轨迹为中心的多目标自然飞越联合设计

日期：2026-09-26。

状态：用户要求归档的思想模型与实现讨论稿。核心思想已确认；下文具体算法、组合方式和实施顺序均待用户拍板。本轮只建立文档，不启动 V4 编程或新实验，不把 V3 的已有模块标记为 V4 已实现。

## 1. 用户确认的核心思想

> 以机动控制所生成的完整轨迹为设计对象，联合选择沿途相遇时刻，使多个目标共享自然飞行弧，并通过整条轨迹的调整降低总机动成本。

轨迹由初始状态和机动历史生成。访问是这条轨迹上的时空接近事件；一个访问不必对应一个机动、一段转移的终点或一条新轨道的起点。可以主动寻找同时容纳多个相遇的自然弧，也可以先传播轨迹发现适合加入的相遇，再共同调整轨迹与相遇时刻。

“完整轨迹为设计对象”意味着早期机动、已有访问和后续连接能够共同改变；不是要求一开始就随机生成可行的 35 目标解，也不是把全任务压缩成一个固定椭圆。轨迹可以由不同自然弧和自由时刻脉冲组成；J2 下的自然弧按动力学演化。

核心判断是全任务原始总 ΔV。多目标共享弧是寻找低成本解的途径，不另设“机动最少”“每弧访问最多”或“始终保持一个轨道面”的任务目标。

## 2. 与 V2/V3 的关系

[MODEL_V2.md](MODEL_V2.md) 已提出试射、单脉冲双目标和片段连接；[MODEL_V3.md](MODEL_V3.md) 已允许自由机动、访问见证和完整 J2 联合优化。因此，V4 不声称首次在数学上允许一弧多目标。

## 3. 数学表述

### 3.1 控制定义轨迹

```text
q = (q0, M, tau[1:M], dv[1:M], T)
x(t;q) = 从初始轨道 q0 出发、执行该脉冲表后的真实 J2 轨迹
J(q) = sum(norm(dv[k]))
```

`q0` 保留初轨六自由度，`M` 为任意非负有限整数。脉冲时刻有序且位于 `[0,T]`；同刻脉冲先矢量合并。目标也从原始状态按同一中心引力加 J2 模型传播。

初始状态、脉冲位置和各自然弧不是互不相关的决策。多重打靶可引入辅助节点，但节点必须通过动力学连接；它只是数值表达。

### 3.2 相遇定义覆盖

每个目标 j 的轨迹距离函数为：

```text
D_j(q) = min over 0 <= t <= T of norm(r(t;q)-r_target_j(t))
完整覆盖要求 D_j(q) <= 1 km，j=1,...,35
在上述条件及继承的任务条件下最小化 J(q)
```

用于数值求解的等价存在性表达为：给每个目标一个自由见证时刻 `theta[j]`，满足

```text
0 <= theta[j] <= T
norm(r(theta[j];q)-r_target_j(theta[j])) <= 1 km
```

见证不必是首次接近或全局最近点。按见证时刻排序可得到一个访问计划，实际首次访问顺序另行检测；同一轨迹可能有多个有效计划。不同目标允许同刻访问。

内层局部求解可以暂时固定相遇窗口或事件次序，外层必须能改变窗口、次序以及访问所属自然弧。最近接近函数可能有多个极小值，直接使用 `min` 不能消除组合搜索。

### 3.3 共享自然弧与整体连接

自然弧是两个实际脉冲之间的无推力传播区间，包含初始与末端滑行。弧上可有零、一个或多个目标；访问本身不划分动力学弧。

例如，一条候选包含“脉冲 u1 -> A、B、C -> 脉冲 u2 -> D、E”。构造时允许共同调整 u1、u2、其时刻和 A 至 E 的见证；不能以把 A/B/C 命中后锁死 u1 作为永久规则。D/E 的连接需求可以反过来改变前一条自然弧。

弧段入口/出口可以作为临时局部变量或锚点，不能变成永久不可动的任务条件。局部省油可能造成后续更贵，只有完整任务重新连接与评价后才能报告净收益。尚未完整覆盖的候选只能报告部分构造与剩余目标诊断。

## 4. 继承的任务与工作约定

本节用于版本衔接，具体物理定义沿用 V3，不重新展开历史证明。

- 35 个原始目标；历元 UTC 2035-01-01 12:00:00；时长不超过 864000 s；全过程高度不低于 200 km；有效飞越距离不超过 1 km。
- 初始半长轴位于 `RE+[590,610] km`，`0<=e0<0.001`，轨道面和相位自由。仅中心引力与 J2；内部单位 km、s、rad、km/s。
- 初始与中间自然滑行、多圈、延迟机动、零访问过渡、自由机动数量均保留。不要求交会速度匹配，不引入论文中的相对速度限制、规则星座或共面条件。
- 搜索接纳门槛仍为 `J<=6.1 km/s`；单次瞬时倾角改变超过 5 度的搜索惩罚及拒绝候选负反馈约定仍保留。它们与原始 J 分开记录，不新增为物理约束。
- 用户当前通知验收线为真实冷启动、独立 J2 完整 35/35、原始 `J<8 km/s`。6.1 至 8 之间的合格物理解同样须报告验收，但不能因此进入门槛为 6.1 的合格工作池/elite。修改搜索池政策须另作决策。
- 默认空历史输入；不得加载历史轨迹、顺序、脉冲或信息素。原始目标几何可用于构造。队友顺序只属于此前明确授权的特定对照，不自动成为 V4 起点。
- MATLAB、`+ctocscreen`、double、MAT 文件约定不变。独立固定原脉冲 J2 全任务复核不省略，`official_alignment_verified` 不因新模型改成 true。
- 保留历史、提交与回滚点；不启动 ATK、不代跑正式 24 分钟批次。本轮停留在归档与讨论，之前持续改进授权不作为绕过本次拍板过程的依据。

## 5. 具体实现路线：全部待选

以下是基于文献的工程方案，不是声称某篇论文已经完整实现了 CTOC14 V4。路线可组合，但不能未经讨论把所有机制叠加成默认版本。

### A. 自然弧发现 + 多相遇共同打靶 + 状态集束

1. 从合法初轨和真实候选状态生成自然传播、延迟脉冲和不同方向/时长的候选弧。
2. 扫描目标的时空接近窗口，保留同一目标的不同圈次机会，提出共享弧的双目标/三目标组合。组合由轨迹机会生成，不预先把 35 个目标永久分组。
3. 同时调整一个脉冲、其时刻和多个相遇时刻，使多个目标在同一条真实自然弧上满足距离条件；必要时开放前一段控制或提出增加脉冲的替代拓扑。
4. 将构造结果加入状态集束。节点含真实状态、时刻、覆盖集合和完整控制历史；可继续使用 Beam P-ACO 组织候选选择。
5. 新增目标或连接困难时，对已构造轨迹共同调整，而非只有获得 35/35 后才开放早期机动。可传播候选的后续自然尾弧用于发现未来机会。

具体共同打靶形式：把所有计划相遇的位置残差堆叠成一个向量，对同一组控制求解，而非为每个目标独立求一个脉冲。若使用线性化，

```text
delta r_relative_j ~= (d r_inspector / d p) * delta p
                    + (v_inspector - v_target_j) * delta theta_j
```

`p` 包含参与调整的控制和初轨参数；导数在同一传播轨迹上计算。加入信赖域后寻找共同可修正方向，再进行非线性 J2 重算。距离近不一定修正便宜；共享控制对多个目标的修正要求还可能互相冲突。修正代价估计仅作启发式，不声称是严格下界。

优势：有具体的多目标构造原语，较易保留不同路线；最贴近 Jing 的机会发现、Xia/Su 的共同相遇以及 Beam P-ACO 的组织方式。

主要缺口：真实三维 J2 下共享弧可能稀少；固定入口的一次脉冲不一定有足够自由度完成任意组合。只向前追加仍会固化前缀，必须明确何时回调已有控制。双/三目标只是起步提案规模，不是模型上限。

### B. 完整时域轨迹骨架 + 自由相遇时刻 + 联合变形

1. 从原始目标几何构造多组初轨、少量机动和覆盖任务时域的轨迹骨架。骨架可以尚未覆盖 35 个目标，且不使用旧轨迹。
2. 为全部目标在候选轨迹上寻找多个接近窗口，以这些窗口初始化自由见证时间。
3. 以稀疏多重打靶同时调整初轨、所有脉冲、机动时刻和相遇时间。可比较逐步加入目标与从一开始纳入全部目标两种恢复方式。
4. 可将扩大相遇容差后逐步收紧作为求解延续策略；中间状态仅为恢复提案，正式阈值仍为 1 km。
5. 外层重新分配相遇窗口、移动/增删机动、改变圈次，随后再解整个联合问题。

优势：从早期就允许未来访问改变早期机动，最直接落实“整条轨迹共同调整”。作为 A 的联合内核时，也可以对当前全部已选事件与后续提案共同求解。

主要缺口：冷启动骨架离目标太远时，连续优化容易进入无效局部极小；窗口更换、拓扑改变和有质量的初猜不可省略。扩大距离容差不保证连续收紧后存在解。不能只把旧 fmincon 入口重新命名为 V4。

本路线的多重打靶基础继承 V3；骨架生成、窗口选择及延续调度是待论证的迁移设计，不冒充上述新论文的原算法。

### C. 多目标自然弧族 + 自由边界连接 + 全任务调整

1. 在目标星历中发现可能由共同自然弧容纳的目标/时刻组合，生成多种弧候选。
2. 每个弧候选保留入口/出口状态、时刻及可调整参数；不是只保存目标集合和一个局部成本。
3. 搜索弧的覆盖组合与时序，同时求解连接。边界时空位置不同时，必须计算真实转移；只有同一位置、同一时刻的速度差才直接对应一个连接脉冲。
4. 选出整条候选后共同调整弧形、连接、初轨和见证；允许拆分、合并与替换弧组。

优势：把大量逐目标选择压缩为少量有物理意义的弧段组合，也能从任务中部向两端设计，不必每次从初始轨道逐目标展开。

主要缺口：独立弧很省油不代表从低初轨出发且弧间连接也省油；不可用静态集合覆盖代替连续连接。建立轨迹/片段库是新增实施范围，当前未授权自动预处理；选择本路线后再明确在线生成或离线库及预算。

借鉴 Cataldi 的滑行弧构件表示、Huang 的组内自然巡访与组间连接思想；自由边界及全任务联合化是本项目提出的迁移方案。不能把规则星座的解析构造直接套入异质目标集。

## 6. 横向选择与建议组合

| 决策 | 可选做法 | 当前建议，尚未确认 |
|---|---|---|
| 主要构造方式 | A 状态集束 / B 全时域直接搜索 / C 弧族组合 | A 主动发现多目标弧，B 负责构造过程中的共同调整 |
| 首次纳入目标 | 全部 35 同时恢复 / 分批增加但不永久冻结前段 | 分批形成有效初猜，同时保留全任务目标与共同调整能力 |
| 蚁群的角色 | 延续状态条件经验 / 暂用无经验束搜索 / 更换外层方法 | 可保留，但学习对象需包含弧形、时间与入口状态，不能退回固定目标边权 |
| 连续优化 | 直接射击 / 稀疏多重打靶 | 优先核查并复用 J2 多重打靶内核及导数，避免重写物理层 |
| 脉冲拓扑 | 固定 M / 多种 M 与插入、删除、移位 | 多种 M；不把少脉冲等同于低 ΔV |
| 连接策略 | 锁定片段再拼接 / 连接时调整相邻弧与必要前段 | 后者，并定期开放完整候选 |
| 时刻与顺序 | 固定顺序 DP / 多窗口与事件重分配 | 自由窗口与重分配；DP 可作已给定结构的内部比较器 |

建议组合不是“A 先做出完整高成本解，然后 B 只精修”。预期交互为：A 提出共享弧和后续相遇，B 调整已有轨迹与新相遇，调整后的真实状态再进入 A 的搜索。已选事件的保留/替换和恢复失败的分支管理仍需讨论。

信息素、负反馈和 SA 的具体归因、编码、池政策仍待设计。继续保留原始成本与罚分分离、失败原因区分、有界经验和探索机会；不能把一次共同打靶失败学习成该目标组合永久不可行。

## 8. 如何判断实现确实改变了搜索

下列是待实施的证据要求，不是本轮已开展的测试清单：

- 实际生成过由共同控制求解的多目标自然弧，记录真实脉冲表及相遇，不仅是单目标转移上偶然增访。
- 后续访问加入或更换时，允许并记录早期控制与已有相遇的共同变化，而非只修末端。
- 记录候选的初轨、轨迹形态、访问窗口和拓扑差异；用多个结构的完整成本判断搜索能力。
- 任何局部弧收益最终落实到真实冷启动的完整 35/35 独立 J2 总 ΔV；局部成功只能作为机制证据。
- 必要验证针对“共同弧能否构造”“连接是否吞掉节省”“完整任务是否改善”等可改变决策的问题。预算与具体实验由路线确定后的实施计划规定，不以大量无关回归替代结果。

目前无 V4 求解器、无 V4 新运行、无 V4 成绩。本文不预判冠军轨迹形态，不保证某一路线达到 6.1 或 8 km/s。
