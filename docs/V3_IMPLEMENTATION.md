## 1. 已实现的完整运行链

```text
载入经过签名检查的目标缓存，核验 fmincon 实际可调用
  → 多群初轨采样 / 显式传入历史脉冲表初猜
  → 状态驱动束蚁群：滑行、自由脉冲、J2 修正目标引导
  → 前缀快速补全，提出完整轨迹候选
  → 全变量多重打靶 fmincon 联合恢复和 ΔV 优化
  → 固定初轨与真实脉冲重新传播、全目标搜索和高度区间检查
  → 可行工作池 / 不可行恢复池分离，结构变异后进入同一求解器
  → 完整可行候选进行 SA 接受，独立重放通过者进入导出档案
  → 全任务验证收益回传信息素，共享候选、扩展范围、保存检查点
```

完整机制已接通并不等于已有有效竞赛搜索效率。短时真实数据测试只证明入口、候选生成、联合求解、失败记录和输出能运行。搜索策略、初猜质量和预算分配仍需真实实验评估。

## 2. 统一数据接口与动力学

`schema_version=free_maneuver_v3`，`dynamics_id=central_j2`。候选结构：

| 字段 | 含义 |
|---|---|
| `initial_q` | `[a,ec,es,i,Omega,u]`，完整六变量 |
| `maneuver_times_s` | 任意长度的实际机动时间表 |
| `delta_v_km_s` | M×3 真实惯性脉冲矢量 |
| `duration_s` | 自由任务终止时间 |
| `witness_times_s` | 35×1 访问见证；前缀未知项为 NaN |
| `validation_level` | proposal / 本地筛查，不能继承旧模型标签 |

同刻脉冲按矢量相加后计费；精确零脉冲可移除。允许首脉冲在零时刻、末时刻脉冲、任意零访问弧、跨多圈传播和机动/访问同刻。访问不重置状态、不触发必需机动。

`v3Arc` 使用绝对时间 J2 数值传播；`v3Force` 提供解析空间 Jacobian，联合优化积分 6×6 状态转移矩阵。独立复核使用 `ode89` 和单独书写的径向/轴向 J2 公式 `v3ReferenceForce`，从 CSV 初态重新传播全部目标，不用目标插值缓存自证。极轴基础和坐标假设仍共享，因而独立积分不是 ATK 对齐证明。

## 3. 联合优化器

`v3ShootingProblem` 为一次固定事件次序构建稀疏多重打靶问题；`v3JointOptimize` 使用 solver-based `fmincon` 内点法和 L-BFGS。选择 solver-based 是为了明确稀疏梯度、传播缓存、扁平变量索引和预算回调。本机已经实际执行求解测试，并核验 `optimoptions`，不是仅检查安装目录。

联合变量包含：

- 初轨六变量；a 用中心值 RE+600 和尺度 10 km，ec/es 用 0.001 缩放。
- 所有机动、35 个访问见证、辅助节点和结束时刻；时间尺度 86400 s。
- 每个节点的六维状态，位置尺度 10000 km、速度尺度 1 km/s。
- 全部脉冲分量及非负辅助成本 s；约束 `dv·dv <= s²`，最小化 `sum(s)`。

每个访问和机动均保留自己的事件，即使初猜时刻完全相同也不合并其时间变量；零时长自然弧用恒等状态转移处理。只有初始历元固定为零。外层变异改变访问顺序、跨越机动边界、增删或移动机动，然后重新建立同一个全任务问题。

连续性约束明确连接全部节点。初猜中可以用目标位置初始化辅助节点以帮助恢复，但真实重放从不使用这些节点重置飞行器。采用 STM 的状态导数和端点时间导数构建稀疏约束梯度；初轨转换六变量导数用局部中心差分。对连续弧内部增加高度中点约束，最终高度判定另用区间检查。

默认搜索飞越半径 0.99 km、最终判据 1 km；偏心率约束使用显式内缩 `(1-1e-8)*0.001`。这些数值余量不改变题目条件。有限节点高度约束只是求解离散化，不能单独认证全过程高度。

保存 `exitflag`、求解器输出、初始与最终缩放残差、真实重放结果、耗时及软超时。节点残差或收敛标志与真实可行性分开报告：若固定原脉冲实际重放满足全部条件，可以接纳该真实轨迹，但不能据此称辅助节点已收敛。最终成本重新计算 `sum(norm(dv))`。

对于具有完整见证的输入，保留真实重放通过的原可行解。短预算求解得到不可行或更差结果时，返回 `selected_source=retained_feasible_seed`，不得计作新的优化收益。

## 4. 集束蚁群与多群协同

- 默认两群独立初轨根节点；轨道面方向、相位、a 和偏心率均实际采样。根节点全部保存，不能以种子号不同代替初值不同。
- 节点存储真实时间、位置、速度、访问集合、累计 ΔV 和完整前缀。
- 每次扩展先保留滑行、自由脉冲、目标引导三个动作族的提案；额外提案按状态条件信息素选择动作族。动作数量小于 3 是用户可配置的受限搜索，不能称为全机制采样。
- 目标引导先用二体 Lambert 生成初猜，再通过 J2 STM 修正出发速度；保留随机候选分支。引导的圈数枚举目前最多 6 圈，仅限制该提案器；自由时长、滑行、节点及变异不受此 Lambert 上限限制。
- 信息素特征包含绝对时间、半径、速度、角动量方向、访问上下文、动作族、目标及持续时间尺度。保持非零探索概率，挥发并限幅。只有独立通过的完整任务改善才强化提案路径；这是对产生该完整候选的提案经验的归因，不是给优化后轨迹定义固定边成本。
- 分组保留访问集合、时间和几何状态差异，并预留至少一个零新增访问槽位。启发式剩余成本使用当前真实速度与剩余目标速度差的估计；不声称是下界。
- 快速补全使用真实状态逐步扩展。所有前缀随后进入全任务联合优化，不永久锁定前缀。
- 多群共享完整可行工作池、恢复池和信息素；交替使用新构造候选与结构变异，避免有了工作解后只在其附近搜索。工作池初轨也回流为新构造根节点。

默认参数是首版可运行配置，尚未证明竞争有效。群内选择和快速补全仍较简单，不能根据短时流程测试宣称其全局能力优于其他算法。

## 5. 大幅变异与 SA

八类算子：插入脉冲、删除脉冲、远距离移动脉冲、重采样完整初轨、重排/重新分配访问见证、缩放滑行与任务时长、删除并重建窗口中的过渡链、合并相邻脉冲。每个算子产生的整条候选都重新进入统一联合优化与固定脉冲评价。

仅完整可行候选以真实 ΔV 进入 SA；不可行候选进入恢复池，其残差不冒充成本。记录温度、概率、随机抽样与接受结果。温度初值 0.2 km/s，前五个有效成本差用于量级定标；之后冷却，停滞时升温。历史独立通过的最好解单独保存，不随 SA 上坡变差。

每 8 次外层迭代默认扩大活动机动数、脉冲分量搜索范围和动作时长尺度；插值、束宽、节点界和窗口等仍是有限搜索近似。不能宣称已经穷尽所有有限 M 或所有连续状态。

## 6. 验证与导出

`v3ScanArc` 对每条自然弧搜索全部 35 个目标，包括端点、局部距离极小值和给定见证；不把计划标签当作访问。当前事件扫描用于发现和认证正见证，**不宣称严格证明没有遗漏其他接近事件**。

`v3Height` 对整弧使用自适应区间下界。根据满足高度边界之前的保守加速度界 A，检查中点半区间界：

```text
|r(mid)| - |v(mid)|*h - A*h²/2 >= RE + 200 km + numerical_margin
```

不能通过时继续细分；发现低高度或细分达到最小间隔仍无法确认则拒绝通过。默认数值余量 0.01 km。此处是对数值传播轨迹的保守检查，积分误差仍由容差、数值余量和复查控制，不宣称形式化区间 ODE 证明。

导出必须经 `v3Verify` 固定原脉冲独立连续传播，全部目标独立传播；初轨、时间、高度和 35 个距离≤1 km 见证全部通过。近距离阈值或高度边界的成功候选再收紧步长复查。正式轴系尚未对齐，标签为 `nominal_j2_independent_verified`，不是 `atk_verified`。

合成数据标记 `dataset_kind=synthetic_test_only`，输出放在开发目录。真实入口使用签名验证的竞赛 CSV 缓存，合成案例不能充当成绩。

## 8. 输出、恢复与评估

输出位于 `runs/v3/search/<label>/`：

- `checkpoint.mat`：配置、实现和目标签名、RNG、各群束、真实根节点、信息素、可行工作池、恢复池、独立导出档案、历史记录和失败原因。临时写入后替换。
- `summary.md`：数据类型、实际耗时、调用数、可行池与导出状态。
- `elite.mat`：只在有独立通过的完整候选时生成；包含实际脉冲表和复核结果。无文件即没有该层级完整解，不从恢复池凑一个“最好结果”。

```matlab
z = load(fullfile(folder,'checkpoint.mat'));

disp(state.elapsed_s);
disp(state.budget_overrun_s);
disp(numel(state.history));
if isempty(state.elite)
```

重点分别看：实际访问数/高度是否通过、独立复核的总 ΔV、真实新增改善还是保留初猜、联合求解残差与 exitflag、失败类型、SA 接受记录、多初轨与多群是否实际产生不同候选。目标是同口径降低完整可行任务成本，不以更多机动、更多调用或较小局部残差当作成绩。
