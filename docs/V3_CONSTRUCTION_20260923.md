## 2. 多路径构造

- `v3GuidedTransfer` 的第三输出保留预算内多个通过实际 J2 修正的分支，记录脉冲、分支和到达状态；旧的一、二输出调用维持首个成功分支语义。
- `v3Expand` 为引导动作保留多个成功后继，使用已有多样性束选择器裁剪；自然滑行、随机脉冲、延迟机动与零增访后继仍有构造机会。
- `v3ApplyAction` 从真实前缀状态传播等待段和机动后自然弧，扫描全部目标并检查高度，不覆盖成目标位置或速度。
- `v3Complete` 接收多个入口，每层保留一束后继；完成和停止扩展的分支保留到输出选择。构造候选经前缀两积分一致性筛选，输出多个候选。前缀筛选不是完整任务独立验收。
- 主循环将各候选送入有界 FIFO `fresh_queue`，逐次获得联合求解机会；同物理轨迹和任务目标集去重。队列满时拒绝新入队项，不覆盖尚未处理项。暂不精修的前缀移至队尾。
- 预算耗尽时，已选中的初猜/新构造/恢复提案写回对应队列。恢复提案保留完整目标集、父工作解及停滞次数；该保留操作不算恢复失败。活动提案有一个保留槽，可暂时超过普通队列容量一项。

束宽、分支数和输出数均有限，仍会剪掉部分路径，不能称为穷尽或全局最优算法。原有谱系停滞判定仍主要按覆盖数，第三处未完成前不声称已解决所有构造停滞问题。

## 3. 时间与动态筛选

`v3TimeCandidates` 将巡检器自然传播到目标相同未来时刻，利用 J2 状态转移矩阵的位置对初速度块估计位置修正脉冲。每个时长的传播供全部未访目标复用；不建立目标对、转移或片段预处理库。

估价按名次形成启发概率，结合实际状态信息素；贪心与含探索份额的无放回抽样选择若干目标/时长组合。引导根指定的首目标及时间保留一次尝试机会。估价不是可行性证明或严格成本下界。

`v3TimeSearch` 对选中组合求真实 J2 转移分支，再围绕成功时长向前、向后尝试并逐次缩小步长。局部更新按实际脉冲模长判断，成功动作保留供后续多样性选择，不仅输出局部最优一条。单段变便宜不等于全任务省油，后者仍按统一完整任务成本验收。

CEA 引用的时间优化来源为 Yu Zhang 等，*GTOC12: Methods and results from the National University of Defense Technology*，DOI `10.1007/s42064-024-0247-z`，第 3.3 节 Algorithm 1。原算法在燃料门槛下逐步缩短转移时间；其双脉冲、质量估算、150 kg 门槛、30 天步幅均未移植。本实现是适配本题 Delta-V 目标的借鉴，不是原 TLOACO 的复现。

Beam P-ACO 参考 `https://arxiv.org/abs/1704.00702` 第 3 节及第 5.1/5.2 节。方法审阅与历史缺口见 [V3_METHOD_TRANSFER_REVIEW_20260923.md](V3_METHOD_TRANSFER_REVIEW_20260923.md)。

## 4. 默认搜索近似与记录

| 参数 | 默认值 | 用途 |
|---|---:|---|
| completion_beam_width / completion_outputs | 4 / 4 | 补全束宽及输出上限 |
| guided_keep / fresh_queue_size | 4 / 16 | 引导后继数及待联合候选容量 |
| time_grid_count | 5 | 基础时长网格抽样上限，另可加入引导时间 |
| guided_attempts / guided_branches | 3 / 3 | 组合尝试数及分支尝试上限 |
| time_refine_iterations / time_refine_fraction | 2 / 0.15 | 时间局部搜索轮数及初始相对步幅 |
| branch_greedy_probability / time_rank_power | 0.5 / 2 | 选择概率与名次启发强度 |
| action_min_duration_s | 0.001 | 数值正时长下界 |
| guided_max_revolutions | 6 | 初始 Lambert 分支搜索近似上限 |

圈数上限按既有 `expand_after` 周期增加 2；仍有基于时长的 `floor(dt/5400)` 分支估计。这些均是可配置算法近似，不是竞赛条件。预算是软预算：单次积分、事件扫描或必要复核可超时；阶段边界会停止追加工作，实际耗时和超时量单独记录。

检查点保存 `beam_expansion_history`、`construction_history`、时间候选/试探、各层宽度、候选检查、队列和来源尝试。联合记录含实际输入轨迹键、目标集、是否来自候选队列及父解成本。
