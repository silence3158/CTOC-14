# V3 轨道结构诊断（2026-09-25）

## 目的和边界

本次检查验证“低总 ΔV 任务是否主要是在一个基本轨道状态附近保持，并用小机动调相位”的假设。输入是已经保存的队友策略重建结果 `runs/v3/diagnostics/tail27_20260925_method_search/comparison.mat`。分析只读取固定脉冲重放状态，不启动 ATK，不搜索，也不把队友轨迹作为冷启动输入。

表中的半长轴、偏心率、近地点、远地点和周期是脉冲前后瞬时二体根数，用来描述几何变化；它们不是 J2 全程高度证明。位置不连续的脉冲前后分别统计，避免把脉冲跳变误认为自然传播。

因此，假设只能部分成立：轨道面变化确实受到控制，且没有超过 5° 的单次倾角变化；但轨道能量和形状变化很大，不能称为围绕固定基本状态的保持类轨迹。更准确的描述是：策略通过较大的切向和径向速度改变轨道能量、周期和相位，再把非共面代价限制在较小范围内。总 ΔV 本身不能推出“只是在保持轨道”，因为小的切向速度变化会在数天内积累成很大的沿轨相位变化。

这里的“相位”应作为可计算量处理：给定脉冲前状态，可计算半长轴/周期和轨道内真近点角；给定同一参考轨道，还可以计算平均经度或相对轨道元素随时间的漂移。不能只用总 ΔV 或单次法向分量宣称相位优化。

## 可借鉴的文献和公开资料

1. **朱阅訸，面向大规模目标访问任务的飞行序列规划方法，国防科技大学博士论文，2020。** 本地全文 `literature/面向大规模目标访问任务的飞行序列规划方法_朱阅訸(1).pdf`，摘要和第六章（约第 108–127 页）直接讨论大规模目标飞越。该文明确把“试射+微调”分开：先用随机滑行时间和脉冲找潜在多目标组合，再用优化微调到可行；随后以片段终端状态作为下一片段起点进行累加搜索。第六章还观察到较平滑轨迹的脉冲方向基本沿速度方向，减少不必要的时间损耗。它与本次“主要用切向能量/相位调整、控制轨道面变化”的诊断最接近，但问题是 GTOC-X 飞越，动力学和目标约束不等同于 CTOC-14。

2. **张雅声、周海俊，基于穿越点的多目标交会轨道设计方法，现代防御技术，2013，41(5)。** 本地全文 `literature/基于穿越点的多目标交会轨道设计方法_张雅声.pdf`，摘要提出对非共面多目标引入“穿越点”，再用曲线拟合设计多目标交会轨道。可借鉴点是把“在哪个轨道几何位置安排访问”写成穿越点和几何拟合变量，而不是口头说“有利位置”；其模型仍是多目标交会示例，不能直接证明 CTOC-14 的最优结构。

3. **Schaub and Alfriend, “J2 Invariant Relative Orbits for Spacecraft Formations,” 2001, DOI: [10.1023/A:1011161811472](https://doi.org/10.1023/A:1011161811472).** 论文研究通过选择相对轨道元素使 J2 长期相对漂移抵消，从而降低编队保持需求。它为“利用自然摄动特性减少保持机动”提供了严格的相对轨道元素背景，但研究对象是近距离编队相对运动，不是 35 个远距离目标的飞越序列；不能直接迁移成 CTOC-14 的目标函数。

4. **Gaias and D’Amico, “Impulsive Maneuvers for Formation Reconfiguration Using Relative Orbital Elements,” 2015, DOI: [10.2514/1.G000189](https://doi.org/10.2514/1.G000189).** 论文以相对轨道元素表达编队重构的漂移和脉冲代价。对本项目有用的是把平面、形状和沿轨相位分量分开建模，并根据漂移时间选择脉冲时机；其编队重构场景和 CTOC-14 的远距离目标访问仍有明显边界。

5. **Simoes et al., “Beam P-ACO: Beam P-ACO for the GTOC 5 asteroid routing problem,” arXiv:1704.00702，代码：[lfsimoes/beam_paco__gtoc5](https://github.com/lfsimoes/beam_paco__gtoc5).** 文中第 5.1 节将轨道相位/几何指标作为廉价的候选筛选信号，并提醒长时间贪心会带来后续代价。它支持把相位几何作为构造启发式，但不是“保持基本轨道”的物理论文，且使用的转移模型和 CTOC-14 不同。

## 对 V3 的含义

应把“保持类”改写为三个独立、可验证的搜索特征：

- 轨道面代价：真实脉冲前后角动量方向变化；
- 能量/形状代价：半长轴、偏心率、近远地点或相对轨道元素变化；
- 相位代价：在给定自然传播时间下的沿轨相位漂移和目标交会窗口。

搜索中可以用这些量做构造启发式和多样性特征，但最终仍必须用固定原脉冲的独立 J2 重放验收。不能把 5° 轨道面阈值当成“轨道基本状态保持”的充分条件，也不能把这条队友策略的诊断结果当作冷启动搜索成绩。
