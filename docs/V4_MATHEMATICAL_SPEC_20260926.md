# V4 可指导实现的数学规格：事件型轨迹优化与 A+B 搜索

日期：2026-09-26。对应用户要求：“推理一下完整可指导代码的数学结构”。

本文是设计推导，尚未实现或运行 V4。已确认的 A+B 分工、B 的范围与任务模式以 [MODEL_V4.md](MODEL_V4.md) 为准。本文推荐的笛卡尔初态编码、事件型多重打靶、顺序二阶锥子问题及具体反馈表达是待讨论的数值方案，不把它们记成用户已经批准的实现。

推导分三层：原始物理问题；给定结构的一次连续求解；改变结构与分配计算的外层搜索。后两层的窗口、信赖域、束宽和采样都不是赛题条件。

## 1. 物理对象与原始问题

### 1.1 常量、状态和自由控制

目标集合固定为 `U={1,...,35}`。采用 km、s、rad、km/s，`t=0` 对应 UTC 2035-01-01 12:00:00，`Tmax=864000 s`。令

\[
x=(r,v)\in\mathbb R^6,\quad P_r=[I_3\;0],\quad
G=\begin{bmatrix}0\\I_3\end{bmatrix},\quad R_{\min}=R_E+200.
\]

一条物理控制历史为

\[
q=(x_0,M,\tau_{1:M},u_{1:M},T),\qquad
0\le\tau_1\le\cdots\le\tau_M\le T\le T_{\max}.
\tag{1}
\]

`x0` 是历元处任何脉冲施加前的初态；`u_k` 是惯性系中的实际速度增量，`M` 可为零。先规范化真正同刻的脉冲，再定义

\[
J(q)=\sum_{k=1}^M\|u_k\|_2.
\tag{2}
\]

同刻脉冲矢量相加后只形成一次速度跳变；`||u1+u2||` 与 `||u1||+||u2||` 不可混用。接近但不相等的时刻不能因数值方便而静默合并。初轨自由设计不额外收取从另一条固定轨道出发的发射脉冲。

### 1.2 统一 J2 流

自然弧满足

\[
\dot x=f(t,x)=\begin{bmatrix}v\\a(t,r)\end{bmatrix},\quad
a=-\frac{\mu r}{R^3}+\frac{3J_2\mu R_E^2}{2R^5}
\left[\left(5\frac{z^2}{R^2}-1\right)r-2z\hat k(t)\right],
\quad R=\|r\|,\quad z=\hat k(t)^Tr.
\tag{3}
\]

`k(t)`、常量、时间尺度和原始目标状态继承经核对的 nominal J2 数据模型。不能因重写优化层把目前的极轴假设改成另一套。用

\[
\Phi(t_b,t_a,z)
\]

表示从 `z` 在 `ta` 出发自然传播到 `tb` 的六状态。脉冲满足

\[
x(\tau_k^+)=x(\tau_k^-)+Gu_k.
\tag{4}
\]

各目标 `x_j(t)` 由其原始初态按同一动力学生成。没有速度匹配条件。初轨、每次机动后的状态和目标状态不能互相重置。

### 1.3 初轨用六维笛卡尔变量表达

建议直接优化 `x0=(r0,v0)`，避免近圆/赤道轨道的角根数奇异性。它与原有六自由度初轨等价，不是放开初轨条件。令

\[
\alpha(x_0)=\frac{2}{\|r_0\|}-\frac{v_0^Tv_0}{\mu}=\frac1{a_0},
\quad
e_v(x_0)=\frac{(v_0^Tv_0)r_0-(r_0^Tv_0)v_0}{\mu}-\frac{r_0}{\|r_0\|}.
\]

正式初轨条件为

\[
\frac1{R_E+610}\le\alpha(x_0)\le\frac1{R_E+590},
\qquad \|e_v(x_0)\|_2<10^{-3}.
\tag{5}
\]

严格开边界不能直接写成求解器的闭约束。数值子问题采用 `e_num=0.001-delta_e`，`delta_e>0` 显式记录；最终复核原始严格条件。它是向内的数值余量，不改变题目。初轨条件施加在脉冲前 `x0`，不能施加在历元脉冲后的速度上。

### 1.4 飞越和全程高度

原始任务精确表达为

\[
\begin{aligned}
\min_{M\in\mathbb N_0,\;q,\;\theta_{1:35}}\quad&J(q),\\
\text{s.t.}\quad &(1),(3),(4),(5),\\
&0\le\theta_j\le T,\quad
\|P_rx(\theta_j;q)-r_j(\theta_j)\|_2\le1,
&&j\in U,\\
&\|P_rx(t;q)\|_2\ge R_{\min},&&\forall t\in[0,T].
\end{aligned}
\tag{6}
\]

这是带离散机动结构、连续控制和连续相遇时刻的非凸问题。`theta_j` 是一个有效见证，不必是首次接近、局部最近点或全局最近点。因此不加“相对位置与相对速度正交”作为飞越约束。

一个目标只需一个合格见证；不同目标可以同刻访问。末端速度自由，末端没有交会脉冲。`T` 不必等于十天，目标函数也不含任务飞行时间。完整 35 目标问题之外的部分覆盖排序属于搜索组织，不能代替式 (6)。

固定 `M` 时，物理控制变量有 `7+4M` 维，加上全部 35 个见证为 `42+4M` 维。辅助节点和成本上图变量会增加优化器维数，但不增加物理自由度。

## 2. A 给 B 的离散任务

一次 B 任务定义为

\[
\mathcal H=(M,\mathcal C,\pi,\mathcal W,\mathcal F,\mathcal R,\text{scope},\text{purpose}).
\tag{7}
\]

| 符号 | 精确定义 |
|---|---|
| `M` | 本次固定的实际机动槽位数，允许槽位脉冲为零 |
| `C` | 本次要求满足的目标集合，最终任务集 `U` 始终不变 |
| `pi` | 初始、机动、见证、结束事件的有序身份列表，包含明确的同刻分支约定 |
| `W` | 每个活动目标当前选择的绝对相遇时间窗口；不是全任务永久窗口 |
| `F` | 本次开放的初态、脉冲、机动时间、见证和结束时间变量 |
| `R` | 本次明确撤销的旧见证承诺及原因；目标仍属于 `U` |
| `scope` | 局部窗口、扩大窗口、完整控制历史 |
| `purpose` | 保留并扩展、降低成本、撤销见证后重构 |

事件次序和窗口是一次光滑子问题的局部坐标域。事件交换、换圈次、访问跨过脉冲、机动插入/删除/合并由 A 建立新 `H`。B 的约束评价过程中不排序事件、不截断时间、不自动换目标所属弧。

一次求解可能只要求 `C` 中的目标，故不能把“B 求解成功”解释为 35/35。`C` 的选择由任务模式给出：设旧承诺集合为 `C_old`、真实已检测覆盖为 `V(q)`、新增目标为 `N`，建议默认

\[
\begin{array}{ll}
\text{保留并扩展:}&\mathcal C'=\mathcal C_{old}\cup V(q)\cup\mathcal N,\\
\text{降低成本:}&\mathcal C'=\mathcal C_{old}\cup V(q),\\
\text{重构:}&\mathcal C'=((\mathcal C_{old}\cup V(q))\setminus\mathcal R)\cup\mathcal N.
\end{array}
\tag{8}
\]

加入实际覆盖时，为新增承诺附上真实传播找到的见证初猜。一次成功后覆盖重新计算；删掉承诺并不会强制该目标变成未访问，仍实际飞越就仍计入。保留父分支，使重构不销毁原轨迹。

## 3. 事件型多重打靶

### 3.1 索引和时间别名

按 `pi` 建立节点 `l=0,...,L`，其中 `t0=0`、`tL=T`，时间非降序。每次机动有节点映射 `b(k)`，每个活动目标有见证映射 `h(j)`：

\[
\tau_k=t_{b(k)},\qquad\theta_j=t_{h(j)}.
\tag{9}
\]

`tau`、`theta`、`T` 与其节点时间是同一变量的别名，不能重复放进变量向量后忘记等式。纯数值分段节点可用相邻事件时间的固定比例生成；其时间不是新增任务自由度。统一写成 `t=A_t w+b_t`，`w` 保存独立事件时间。

一般相遇和脉冲即使初猜同刻，也保留为可独立移动的事件槽位，并允许零时长段。只有 A 显式提出同时事件块时才共用一个时间变量。不能用 `unique(times)` 把初猜中的偶然同刻永久绑定。

### 3.2 节点状态和跳变

`y_l` 表示该节点自身脉冲施加前的状态。令 `U_l` 为该节点脉冲；无脉冲时为零，通常 `U_l=u_k`。定义

\[
z_l=y_l+GU_l,\qquad
c_l=y_{l+1}-\Phi(t_{l+1},t_l,z_l)=0,
\quad l=0,\ldots,L-1.
\tag{10}
\]

初态取 `x0=y0`；若使用另一个独立 `x0` 变量，就必须另加 `y0-x0=0`，两种编码只能选一种。建议直接使用 `y0`。

见证节点没有隐含脉冲；在一条自然弧内部加见证或数值节点只把积分分段。消去式 (10) 的辅助状态后恢复同一条物理轨迹。保留断开的节点只能用于数值恢复，不能当作已访问轨迹。

对同刻顺序槽位，`Phi(t,t,z)=z`。若见证在同刻脉冲之前，它读脉冲前速度；之后则通过恒等传播读脉冲后速度，两者位置相同。节点字段须明确速度侧，不能把所有同刻节点都称为整个事件块的脉冲前态。

### 3.3 给定任务的完整连续子问题

设 `rho=1-delta_r` km，`delta_r>=0` 为显式搜索余量；`H_s` 是搜索高度余量。引入 `s_k>=0`，求

\[
\begin{aligned}
\min_{Y,w,U,s}\quad&\sum_{k=1}^M s_k,\\
\text{s.t.}\quad&c_l=0,&&l=0,\ldots,L-1,\\
&\|u_k\|_2\le s_k,&&k=1,\ldots,M,\\
&\|P_ry_{h(j)}-r_j(t_{h(j)})\|_2\le\rho,&&j\in\mathcal C,\\
&x_0=y_0\text{ 满足初轨条件},\\
&0=t_0\le\cdots\le t_L\le T_{\max},\quad t_{h(j)}\in\mathcal W_j,\\
&\|P_r\Phi(t,t_l,z_l)\|_2\ge R_{\min}+H_s,
&&t\in[t_l,t_{l+1}],\\
&\text{未开放的物理控制按本次任务固定。}
\end{aligned}
\tag{11}
\]

窗口、次序、冻结变量和正的数值余量使式 (11) 成为式 (6) 的局部搜索子问题；把这些限制解除并联合全部结构，才对应原模型。这里不施加交会速度、每目标一个脉冲、最大圈数或固定轨道面的约束。

`||u_k||<=s_k` 是精确二阶锥，最小化后 `s_k=||u_k||`。不能声称“增加 s 就把所有约束变光滑”：直接调用范数仍在原点不可微；改成 `u'u-s^2<=0` 又在 `(u,s)=(0,0)` 梯度为零。建议在凸子问题中直接保留锥结构。

## 4. 可以直接组装的导数

以下 Jacobian 均用“约束为行、变量为列”。MATLAB 接口若要求转置，在适配层统一转换。

### 4.1 流的状态和端点时间导数

令 `P_l=dPhi/dz`，沿自然弧积分

\[
\dot P=f_xP,\quad P(t_l)=I_6,\qquad
f_x=\begin{bmatrix}0&I_3\\a_r&0\end{bmatrix}.
\tag{12}
\]

这里的极轴允许依赖时间。一般非自治流仍满足

\[
\partial_{t_b}\Phi=f(t_b,\Phi),\qquad
\partial_{t_a}\Phi=-P f(t_a,z).
\tag{13}
\]

所以式 (10) 的非零块为

\[
\begin{array}{lll}
c_{y_l}=-P_l,&c_{y_{l+1}}=I_6,&c_{U_l}=-P_lG,\\
c_{t_l}=P_lf(t_l,z_l),&&c_{t_{l+1}}=-f(t_{l+1},\Phi_l).
\end{array}
\tag{14}
\]

再乘时间别名矩阵 `A_t` 与变量缩放矩阵。零时长时状态流为恒等，但沿允许方向展开时间的导数仍来自式 (13)，不能把所有时间导数也设成零。同刻边界采用当前事件顺序一侧的导数。

### 4.2 相遇导数的两种坐标不能混用

独立见证节点的残差为

\[
e_j=P_ry_{h(j)}-r_j(t_{h(j)}).
\]

把 `y` 与 `t` 当作独立优化变量时，

\[
\partial_{y_{h(j)}}e_j=P_r,\qquad
\partial_{t_{h(j)}}e_j=-v_j(t_{h(j)}).
\tag{15}
\]

此处没有再加巡检器速度，巡检器时间变化已经通过动力学等式传递。消去辅助状态、直接对真实轨迹 `r(theta;q)` 求导时，才得到

\[
\delta e_j=S_j\delta p+(v_I(\theta_j)-v_j(\theta_j))\delta\theta_j,
\quad S_j=\partial_p r_I(\theta_j;q),
\tag{16}
\]

其中 `p` 不包含该见证时刻，且此式在不跨脉冲的局部事件域中使用。两种表达等价，但把式 (16) 的相对速度填进式 (15) 会重复计算巡检器运动。

如果目标位置由插值给出，优化导数必须是同一位置插值函数的导数。单独插值一个速度表不自动等于位置插值的导数；需用一致的 Hermite/稠密输出或核对二者误差。最终验证仍从原始目标初态独立积分。

### 4.3 初轨 Jacobian

下面在 `r=r0,v=v0,R=||r||` 处评价：

\[
\alpha_r=-2r^T/R^3,\qquad\alpha_v=-2v^T/\mu,
\]

\[
(e_v)_r=\frac{(v^Tv)I-vv^T}{\mu}-\frac I R+\frac{rr^T}{R^3},\qquad
(e_v)_v=\frac{2rv^T-vr^T-(r^Tv)I}{\mu}.
\tag{17}
\]

这里 `e_v` 表示偏心率矢量，第二个式子的下标 `v` 表示对速度求导。可在代码中命名为 `eccVector` 与 `dEcc_dVelocity`，避免同名误读。

### 4.4 弧内部高度点

对一条打靶子弧固定采样比例 `sigma in [0,1]`，令

\[
t_\sigma=(1-\sigma)t_l+\sigma t_{l+1},\quad
x_\sigma=\Phi(t_\sigma,t_l,z_l),\quad
g_h=R_{\min}+H_s-\|P_rx_\sigma\|.
\]

若 `P_sigma=dPhi/dz`，则

\[
\begin{aligned}
\delta x_\sigma={}&P_\sigma(\delta y_l+G\delta U_l)\\
&+[(1-\sigma)f(t_\sigma,x_\sigma)-P_\sigma f(t_l,z_l)]\delta t_l
+\sigma f(t_\sigma,x_\sigma)\delta t_{l+1},\\
\delta g_h={}&-\frac{(P_rx_\sigma)^T}{\|P_rx_\sigma\|}P_r\delta x_\sigma.
\end{aligned}
\tag{18}
\]

高度点和数值节点可以自适应增加，但在一次模型预测与接受比较期间必须固定。发现新低点后重建约束、重新计算基准残差，不能拿不同采样集合的罚函数作下降比。

### 4.5 控制的真实影响与共享弧

对固定未来观察时刻和惯性系脉冲分量，消元后的敏感度为

\[
\frac{\partial x(t)}{\partial u_k}=P_{t\leftarrow k}G,\qquad
\frac{\partial x(t)}{\partial\tau_k}
=P_{t\leftarrow k}[f(\tau_k,x_k^-)-f(\tau_k,x_k^+)],\quad t>\tau_k.
\tag{19}
\]

`P_{t<-k}` 包含后续各自然弧和既定脉冲跳变的导数。惯性系固定增量的跳变状态导数为 `I`；若改用随状态旋转的 RTN 控制分量，必须额外求旋转基的导数，不能直接沿用式 (19)。建议内部优化统一用惯性系脉冲。

在本题 `f^- - f^+=[-u_k;0]`。由此得到三个直接的实现结论：

- 晚于见证的脉冲没有该见证的位置修正能力；当刻脉冲也不能改变当刻位置。
- 零脉冲可以通过改变其矢量激活，但其时刻的一阶影响为零。新插入零脉冲需要 A 提供不同时间初猜，不能指望一次一阶求解自行找到所有插入位置。
- 同一早期脉冲的同一组三列敏感度进入多个目标残差。共享弧的含义正是这些目标共同约束同一组控制，绝不是分别解完后拼接。

例如固定入口和脉冲时刻，一次脉冲访问 `m` 个目标，只有 `3+m` 个连续修正量：三维脉冲与 `m` 个见证时刻，而中心瞄准有 `3m` 个标量要求。任意双/三目标组合并不普遍可解。1 km 球、开放脉冲时刻、初轨与前后控制会改变可行空间。联合 Jacobian 的秩和奇异值可帮助判断当前线性修正困难，但不能证明该目标组合全局不可行。

## 5. B 的可调范围与真实影响范围

设物理变量增量为 `d_p`，用选择矩阵 `F` 表示 `d_p=F d_free`；未开放分量严格为零。建议保留完整打靶链，或仅消去精确不变的前缀。

| 范围 | 开放变量 | 仍须施加的约束 |
|---|---|---|
| 局部 | 当前任务指定的若干脉冲/时刻、相关见证，必要的 `T` | 所有活动目标及全部受影响后缀的连接、高度、时间条件 |
| 扩大 | 向前开放能影响失败见证的控制，向后开放连接控制 | 同上；不按“前后各一个目标”机械划窗 |
| 全历史 | `x0`、所有已有脉冲与时刻、活动见证和 `T` | 当前完整历史上的全部任务约束；不等于已选 35 个目标 |

冻结的是控制，不是因控制产生的后缀状态。辅助 `y_l` 不得仅因位于窗口外就固定；改变前段后，它们必须随动力学等式改变。

固定出口回接是另一种受限任务，可增加 `t_b=t_b_ref`、`x(t_b^side)=x_ref`。必须明确固定的是脉冲前还是脉冲后状态，不能两边重复施加或漏算出口脉冲。默认任务不增加该约束，而从新状态执行旧的未开放后缀控制。

如果活动见证早于全部开放控制且初轨也固定，对应位置修正列为零。这是当前任务自由度不足的直接证据，应扩展到更早控制或另换结构；增加更晚脉冲不是修复路径。

## 6. 数值实现建议：顺序二阶锥子问题

依据多重打靶及 SCvx 的线性化、弹性残差和信赖域思想；本题使用精确脉冲跳变与 J2 流，不照搬连续推力离散化。以下给出一套自洽的可编程方案，不宣称已经满足参考论文的全部收敛假设。

### 6.1 变量缩放与残差缩放分开

建议变量自然尺度

\[
L_*=R_E+600,\quad V_*=\sqrt{\mu/L_*},\quad T_*=L_*/V_*.
\]

`S_z` 按位置 `L*`、速度/脉冲 `V*`、时间 `T*` 缩放变量；信赖域为

\[
\|S_z^{-1}d\|_\infty\le\Delta.
\tag{20}
\]

残差另定尺度：位置/相遇/高度用 `kappa_r=1 km`，速度连接用 `kappa_v=kappa_r/T*`，逆半长轴用 `kappa_alpha=1/a_min-1/a_max`，偏心率用 `kappa_e=0.001`。可调整但须记录。残差尺度决定恢复时的数值平衡，不是通过容差；通过容差和最终重放必须另检。

记归一化动力学残差为 `cbar`，相遇矢量为 `ebar_j=e_j/kappa_r`，半径为 `rhobar=rho/kappa_r`。初轨两侧和高度的归一化标量不等式合写为 `g_i(z)<=0`；偏心率矢量约束另保留为锥。

具体取 `a_min=RE+590`、`a_max=RE+610`，初轨两侧为 `(1/a_max-alpha)/kappa_alpha<=0` 和 `(alpha-1/a_min)/kappa_alpha<=0`。高度为式 (18) 除以 `kappa_r`。控制变量缩放后的 Jacobian 用链式法则右乘 `S_z`；残差缩放则左乘各自尺度的逆，两者不能互相替代。

### 6.2 弹性约束与一个凸子问题

在当前迭代 `zbar` 处线性化，决策为增量 `d`、脉冲成本 `s`、有符号连接缺陷 `nu`、非负松弛 `b_j,b_i,b_e`。求解

\[
\begin{aligned}
\bar c+C d&=\nu,\\
\|\bar e_j+E_jd\|_2&\le\bar\rho+b_j,\quad b_j\ge0,\\
g_i+G_id&\le b_i,\quad b_i\ge0,\\
\|e_v/\kappa_e+E_0d\|_2&\le e_{num}/\kappa_e+b_e,\quad b_e\ge0,\\
\|u_k+D_kd\|_2&\le s_k,\quad s_k\ge0,\\
\|S_z^{-1}d\|_\infty&\le\Delta.
\end{aligned}
\tag{21}
\]

`D_k` 提取第 `k` 个脉冲增量。时间顺序、窗口、冻结掩码和时限保持为精确线性约束，不设置时间松弛。把 `nu=nu_plus-nu_minus`，非负分量之和即可表示一范数。式 (21) 是 SOCP，而原问题仍是非凸的。

`nu`、访问缓冲和高度缓冲仅是恢复工具，不进入实际控制表，也不能计为命中。预算结束时允许保存它们供同一任务恢复，但该状态保持 `restoration_iterate` 身份。

### 6.3 恢复阶段与省油阶段

定义精确、无量纲的有限约束残差

\[
V(z)=\|\bar c(z)\|_1+
\sum_{j\in\mathcal C}[\|\bar e_j(z)\|-\bar\rho]_+
+\sum_i[g_i(z)]_+
+[\|e_v(z)\|/\kappa_e-e_{num}/\kappa_e]_+.
\tag{22}
\]

`[a]_+=max(a,0)`。用式 (21) 的线性化表达得到 `Vhat(d)`，消去最小松弛后与式 (22) 在 `d=0` 相等。

恢复阶段最小化 `Vhat(d)`；这时降低残差不记为省油。省油阶段求

\[
\min\;\sum_k s_k/V_*+\lambda\left(\|\nu\|_1+\sum_jb_j+\sum_ib_i+b_e\right).
\tag{23}
\]

这里的罚项只处理求解过程中的等式/不等式缺陷，并非把访问数、时间和 ΔV 混成一个新的竞赛目标。`lambda` 是可调整的约束罚系数，不使用未经说明的固定大常数代替可行性门槛。

进入省油阶段前，必须同时满足：逐项打靶缺陷容差、初轨与窗口条件，以及固定当前物理控制重放后的全部活动访问和搜索高度条件。随后可用重放状态重新初始化辅助节点；这不改变初轨或脉冲，也不把状态移到目标上。

若辅助残差已小而真实重放未通过，不得在零预测改进处反复空转：按第 7.4 节重新建立真实节点基准，暴露实际访问残差，必要时加严连接精度、增加高度约束点或更换任务。重建基准不是一个省油步，也不能沿用此前的 merit 比率。

省油阶段的内部迭代仍可能暂时有缺陷。单独保留已通过实际重放的可行 incumbent；它只有被同一任务要求下真实更好的可行控制替换时才更新。扩展目标引起的成本增加可构成成功构造，不叫成本改善。

### 6.4 预测、实际变化和信赖域

每次比较固定任务、尺度、采样集与 `lambda`。恢复阶段用 `Psi=V`，省油阶段用 `Psi=J/V*+lambda V`。由真实非线性流计算

\[
pred=\Psi(\bar z)-\widehat\Psi(d),\qquad
ared=\Psi(\bar z)-\Psi(\bar z+d),\qquad r=ared/pred.
\tag{24}
\]

用增量后真实脉冲范数和最小残差计算 `Psihat`，不能用求解器尚未收紧的上图量或任意松弛值制造预测下降。`pred` 必须显著为正才计算比率。

- `r` 小于接纳阈值：拒绝该步，缩小信赖域；父迭代保留。
- 达到接纳阈值：更新内部迭代；模型吻合好且步长触及信赖域边界时可扩大范围。
- `pred` 很小而 `V` 仍超限：记录恢复停滞，不能标记可行收敛。
- `pred` 很小且已可行：至多说明当前结构和窗口附近没有有效下降；不能称全局最优。
- 传播失败：拒步并记录数值失败，不产生“该目标不可达”的负反馈。

具体信赖域参数满足 `0<eta_accept<eta_expand<1`、`0<gamma_shrink<1<gamma_expand`。拒绝时取 `Delta_new=gamma_shrink*Delta`；已接纳且 `r>=eta_expand`、步长接近边界时取 `min(Delta_max,gamma_expand*Delta)`，其余保持或对低吻合已接纳步缩小。所有阈值进入配置，不伪装成赛题常数。

省油阶段若最优子问题仍明显使用松弛，可取 `lambda_new=min(lambda_max,gamma_lambda*lambda)`，`gamma_lambda>1`，在同一基准重解；有可靠归一化乘子估计时，再要求罚系数高于相应乘子的对偶范数估计。持续使用松弛也可能意味着局部模型/范围不足；触及上限就转恢复或交回 A，不无限增大罚系数。局部精确罚理论要求相应约束资格条件，不能据此保证本问题恢复成功。调整 `lambda` 后重算基准 merit。信赖域过小、罚系数上限或预算耗尽均有独立退出状态。

### 6.5 MATLAB SOCP 映射

本机 R2024a 源码确认 `secondordercone(A,b,d,gamma)` 表示

\[
\|Az-b\|_2\le d^Tz-\gamma.
\]

对子问题扁平向量 `wsub=[d;s;nu_plus;nu_minus;b;...]`：

| 约束 | `A*wsub-b` | `d'*wsub-gamma` |
|---|---|---|
| 脉冲范数 | `u_k + D_k*d`，故常量参数 `b=-u_k` | `s_k` |
| 相遇球 | `ebar_j + E_j*d`，故 `b=-ebar_j` | `rhobar+b_j`，故 `gamma=-rhobar` |
| 初轨偏心率 | `eccbar + E0*d` | `e_num/kappa_e+b_e` |

其余条件进入 `Aeq/beq`、`Aineq/bineq`、`lb/ub`，使用 `coneprog` 的线性目标。该接口没有初猜参数，不能写成给 `coneprog` 直接热启动 `wsub0`。相邻迭代可复用问题结构和导数缓存，但不能据此声称求解器已热启动。

已确认接口存在，尚未运行时核验工具箱许可证或性能。凸子问题的成功 exitflag 不代表原始非线性约束或实际固定脉冲轨迹通过；子问题不可行也不证明其他窗口/结构不可行。

### 6.6 一次 B 调用的完整顺序

```text
检查 H 的事件、窗口与冻结掩码相容性；保留父候选
按父控制真实重放初始化节点，不把节点放到目标位置
若当前控制已满足本次 C 和搜索条件，进入省油；否则进入恢复
while 尚有本次预算
    评价同一事件域中的非线性约束、STM 与稀疏 Jacobian
    建立并求解当前信赖域内的 SOCP
    子问题失败 -> 记录原因；按范围/数值问题重试或交回 A
    有候选步 -> 精确评价非线性残差，计算 pred/ared
    按比率接纳或拒绝内部迭代；处理结构边界和信赖域
    内部迭代接近可行时 -> 固定当前控制重放并检查完整影响范围
    重放通过 -> 更新本次任务的实际可行 incumbent；恢复转省油
    重放失败 -> 增加缺失约束或重建真实节点基准，继续恢复
end
返回实际候选、未完成恢复状态、真实工作量和分类退出原因
```

求解器停止/退出与队列任务处理完毕是不同状态。新任务的 `C`、窗口或拓扑变化后，旧 incumbent 需按新要求重评，不能直接继承“该任务可行”。

## 7. 连续高度、真实重放与边界事件

### 7.1 有限高度点不能代替全程约束

搜索内采用约束分离：在接受候选处检查各弧的径向极小点及自适应区间，发现不足就加约束点并重新求解。求径向极小点时可用 `r'*v=0`，但有限寻根不能自动证明没有漏掉极小值。

本项目已有 `v3Height` 的自适应区间下界可供复核。对不跨脉冲的区间，中点状态为 `(r_m,v_m)`、半宽为 `h`。在首次触及 `Rmin` 前，加速度保守上界可取

\[
A_{\max}=\frac\mu{R_{\min}^2}\left(1+6|J_2|\frac{R_E^2}{R_{\min}^2}\right).
\]

于是半径下界候选为

\[
R_{lb}=\|r_m\|-\|v_m\|h-\tfrac12A_{\max}h^2.
\tag{25}
\]

若下界高于门槛及数值余量，该段可通过；否则继续分割。达到最小分割尺度仍不能确认时返回“未证实通过”，不能取端点高度代替。中点的积分误差须计入余量；ODE 容差和两次数值解的差异本身不是严格全局误差上界。本项目层级仍是 nominal J2 数值验收，不宣称区间算术证明或 ATK 对齐。

### 7.2 固定控制重放

B 输出的物理候选只取 `x0,tau,u,T`。从初态重新执行原脉冲，不使用辅助节点作真实弧起点、不重新瞄准、不修改脉冲消残差。重放覆盖从零时刻到候选结束，包括初始和末端滑行。

普通候选评估可复用同一控制签名的精确缓存；修改前段则使受影响后缀缓存失效。最终完整结果的独立验收重新积分巡检器与全部 35 个目标，不只查询优化时的插值星历。

### 7.3 同刻、跨序和零脉冲的执行规则

| 情形 | 处理 |
|---|---|
| `M=0` | 只有初轨、见证和结束时间；空成本和为零，仍有完整传播与任务约束 |
| 见证与脉冲同刻 | 位置连续，读正确速度侧；允许相等时间，不强加正间隔 |
| 两个见证交换顺序 | A 建立邻接交换/替代窗口任务，重建事件映射 |
| 见证穿过脉冲 | A 建立新的事件顺序；边界处保存两侧机会 |
| 不同脉冲时刻相撞 | 作为结构边界交回 A，生成矢量合并任务，重算成本、倾角与访问 |
| 脉冲为精确零 | 可以删除并重建拓扑；访问节点继续存在 |
| 脉冲很小但非零 | 删除是一个新控制提案，必须重放；不能按显示精度视为零 |
| 结束时刻有脉冲 | 它不改变此前位置且终端速度自由，删除不损害已有飞越并不增成本；规范化后再复核 |
| 只有数值节点增加/删除 | 控制不变，需核对重放一致性；不算增加/删除机动 |

脉冲合并改变固定结构目标的表达，不能沿用合并前后的不同目标值计算同一次信赖域比率。改变事件图后开启新任务、重新计算基准。

### 7.4 小缺陷如何变成整条轨迹的偏差

设 `y_l` 是打靶节点，`ytilde_l` 是从同一个 `x0` 执行同一原脉冲表得到的真实节点，令 `epsilon_l=ytilde_l-y_l`。由式 (10) 得到

\[
\epsilon_{l+1}
=\Phi(t_{l+1},t_l,y_l+\epsilon_l+GU_l)
-\Phi(t_{l+1},t_l,y_l+GU_l)-c_l
\simeq P_l\epsilon_l-c_l,\quad\epsilon_0=0.
\tag{26}
\]

因此某见证处的位置失配一阶近似为

\[
P_r\epsilon_{h(j)}\simeq
-P_r\sum_{m<h(j)}P_{h(j)\leftarrow m+1}c_m.
\tag{27}
\]

单段最大缺陷小并不约束这项累计影响。可递推式 (26) 作为诊断和选择更严格连接容差的依据，但它忽略高阶项与积分误差，不能替代真实重放。

重放失败时，把辅助 `y` 更新为同一控制真实传播的状态，并保持原脉冲、机动时刻和当前计划见证不变。此时节点连接恢复一致，而原来被断点掩盖的访问残差会显现，随后再做联合恢复。如果失败来自遗漏的弧内低点，先把对应高度条件加入；如果两套积分精度不一致，则记为数值一致性问题并定向处理，不能伪造一个目标残差继续奖励。重建次数有界，反复失败交回 A 或返回数值失败记录。

增加打靶节点能改善单段线性化，但不能单独保证式 (27) 的累计偏差消失。改变节点网格或容差后重算基准和缓存签名，不把旧节点残差与新残差直接比较。

## 8. A 如何产生可求解的结构，而不是逐目标锁死

### 8.1 冷启动根

自由根可采样合法 `a,e`、均匀球面轨道法向、面内近地点方向与真近点角，转成笛卡尔 `x0`；`e=0` 时按物理初态去重，不把退化角度当作多样性。几何根用原始目标传播得到的轨道面/相位信息提出初态，但仍投回正式初轨范围并真实传播。

混合比例和扰动尺度是记录的采样配置，保留自由根配额。所有根从 `M=0` 或本轮新生成的控制开始，没有历史顺序、脉冲、旧信息素或旧轨迹输入。

### 8.2 相遇机会扫描

对当前真实轨迹和全部目标定义

\[
d_j(t)=r_I(t)-r_j(t),\quad
F_j(t)=\tfrac12\|d_j(t)\|^2,\quad
\dot F_j=d_j^T(v_I-v_j).
\tag{28}
\]

在各自然弧内搜索多个接近极小值，检查弧端点和脉冲两侧导数，保留同一目标不同圈次的候选时间窗口。式 (28) 用于发现初猜，绝不是最终飞越必须满足的额外条件。

扫描是有限的机会发现算法，未找到见证表示“本次未找到”，不是证明整段无飞越。记录已证实的命中、搜索过的窗口与尚未细查的区间；最终计数只用实际有效见证。

### 8.3 多目标共同修正的便宜估价

对同弧目标集合 `K`，用式 (16) 组装同一组控制的敏感度：

\[
d_j^0+S_j\delta p+w_j\delta\theta_j,
\qquad w_j=v_I(\theta_j)-v_j(\theta_j).
\]

在有限信赖域内共同满足

\[
\|d_j^0+S_j\delta p+w_j\delta\theta_j\|\le\rho+\beta_j,
\quad j\in\mathcal K.
\tag{29}
\]

可先最小化违反量，再在小违反量下估计改变后的脉冲模长和。这里估计的是 `sum ||u_old+delta_u||`，不是把 `sum ||delta_u||` 当作新总成本。前者会识别撤销原机动带来的节省，后者只衡量改动幅度。

该估价仅用于筛选提案；保留原有活动见证的相关约束，或明确标记为“忽略后缀的乐观局部估价”。它不是全局下界，更不能取代式 (11) 的 B。线性修正失败可换窗口、组合、早期控制或机动结构。

### 8.4 三类动作及拓扑闭包

| A 动作 | 新任务如何构造 |
|---|---|
| 已有弧内加入 | 加目标见证节点与窗口，共同调整所属弧的控制；不自动增加脉冲 |
| 尾部延伸 | 延长自然弧或提出延迟机动/过渡链，再共同调整已有和新增控制 |
| 区段替换 | 显式撤销指定承诺，提出新窗口、脉冲插入/删除/合并、事件重排，重放后保留其他要求 |

连续零访问弧允许作为过渡；双/三目标组合只是提案规模，不是每弧最多访问几个目标。发现更多目标时可反复增添见证。所有动作都有进入局部、扩窗和全历史 B 的路径。

单批的机动数上限、时间窗个数、圈次扫描范围和组合规模均为显式可扩展的搜索配置。记录实际裁剪，不把有限枚举失败写成所有机动结构或多圈轨迹失败。

## 9. 状态集束、反馈和调度

以下是沿已确认 Beam P-ACO 方向给出的具体化建议。公式是本项目迁移设计，不冒充原论文已经解决了本题的自由拓扑 J2 问题。

### 9.1 束节点必须保存完整候选

束节点包含 `(q,V,C,H,actual_report,lineage,task_state)`。只保存末端 `(t,r,v)` 不够，因为 B 会回调初轨和早期控制。末状态是比较未来机会的特征，不是完整搜索状态的替代物。

候选先按任务状态、覆盖组合、时间/末状态、弧形和根谱系分组，再在组内比较成本、恢复进展与修正估计，保留多组代表。不同末状态的两个部分候选，不能仅凭一个当前成本更小、访问数更多就宣布另一个被物理支配。

### 9.2 状态条件动作概率

对有限提案集合 `A(q)`，定义同一套读写特征

\[
\phi(q,a)=\operatorname{bin}(t_a,x_a,V_a,\text{action type},\mathcal K,
\text{window},\text{duration/control descriptors}).
\]

`t_a,x_a,V_a` 必须来自该动作锚点的真实传播；方向、时间与状态的分箱尺度写入配置。细状态用于准确归因，粗状态只作有遗忘的启发式，不代表动力学等价。建议

\[
w(a)=\left[\frac{\tau^+(\phi)}{1+N(\phi)}\right]^{\alpha}\eta(q,a)^{\beta},
\qquad
p(a|q)=(1-\epsilon)\frac{w(a)}{\sum_{a'}w(a')}+\frac\epsilon{|A(q)|}.
\tag{30}
\]

正信息素和有效权重都有正下界；`epsilon>0` 保留探索。`eta` 可由式 (29) 的修复成本排序在各动作族内生成，估价失败/未执行有独立状态，不能把它们赋成物理不可达。覆盖进展用于束分层与调度，不混入最终 ΔV。

这仍是有限候选上的选择概率；它不保证有限时间探索任意连续轨迹。初轨、零访问过渡、结构重建与全历史 B 的机会还需要独立配额，不能全部押在式 (30) 上。

### 9.3 有限正种群和负反馈

正成功种群 `P+` 仅包含本轮独立完整物理通过且 `J<=6.1` 的解。一种有界 P-ACO 表达为

\[
\tau^+(f)=\operatorname{clip}\left(
\tau_0+\frac Q{L_P}\sum_{p\in P^+}w_p\,1_{f\in E(p)},
\tau_{\min},\tau_{\max}\right).
\tag{31}
\]

`LP` 为种群容量，`wp` 为有界质量权重，`E(p)` 是从实际最终轨迹重建的特征集合。成员替换/淘汰撤销原贡献；相同物理结果不能因计划改名重复奖励。完整结果形成前，正成功表可以保持中性；实际构造进展进入启发式与队列，负反馈从已执行控制得到。若另设前缀经验表，必须明确与式 (31) 的完整成功奖励分开。

真实脉冲前后角动量 `h-=r cross v-`、`h+=r cross(v-+u)` 给出

\[
i^\pm=\arccos\frac{h^\pm\cdot\hat k_{ref}}{\|h^\pm\|},\qquad
p_i=\left[\frac{[|i^+-i^-|-5\pi/180]_+}{5\pi/180}\right]^2.
\tag{32}
\]

`k_ref` 是项目明确记录的倾角参考轴，前后采用同一轴；不是默认替换为时间变化的动力学极轴。轨道面法向夹角另报，不能与倾角差混淆。角动量退化时记录未定义，不偷偷取零罚分。

成本超限证据为 `[J/6.1-1]_+`。可按各实际脉冲成本占比分配给其状态特征，与倾角罚组合成截断损失 `ell_f`。该分配是可遗忘的经验归因，不证明某一脉冲是高成本的唯一原因。负表按

\[
N_{n+1}(f)=\operatorname{clip}((1-\rho_N)N_n(f)+\ell_f,0,N_{max})
\tag{33}
\]

更新；同一观察去重。超限候选仍可送去改变已有控制，不能因为旧前缀成本高就断言所有重构都超限。预算中断、数值失败和一次局部恢复失败不产生“目标永久不可达”罚。

B 改变前段后，应从新轨迹重建被奖励/惩罚的实际特征，不能照抄修改前的整条动作谱系。反馈键的查询与写入使用同一函数；命中率、去重数及非中性使用数需要记录。

### 9.4 保证存在执行机会的调度

用“根构造、扩展、重构、全历史 B、完整验收”等队列及服务计数组织预算。各必需队列设置可配置最大等待轮数/保留机会，并记录是否真正执行。全历史 B 不只在局部失败时触发，合格池是否为空也不关闭新根的完整构造。

`scope`、`purpose`、窗口与拓扑变化都生成不同任务。失败处理至少区分 `not_started`、`budget_interrupted`、`numerical_failure`、`restoration_stalled`、`nonlinear_replay_failed`、`cost_rejected`。只有实际执行过的求解才消耗相应尝试记录；零步调用不封死以后机会。

子问题无法恢复时，根据非零残差及控制敏感度决定扩窗、回调更早控制、撤销见证、换圈次或换拓扑。残差只解释当前尝试，不能作为整个组合的不可行证明。

## 10. 候选身份、接口与结果门

### 10.1 三种对象不能共用一个“成功”字段

| 对象 | 内容和用途 |
|---|---|
| `control_candidate` | 初态和规范化脉冲表；可真实重放，另存实际访问、高度、成本 |
| `restoration_iterate` | 给定任务的辅助状态、松弛、信赖域、罚系数；可能动力学不连接 |
| `verified_result` | 固定原控制的独立完整验收证据；另判成本池准入与用户通知 |

真实覆盖是 `V(q)={j:存在已核实见证使距离<=1}`，计划集合 `C`、计划顺序和节点命中数都不能替代它。改变控制后旧的 `V` 自动失效；重新传播后再赋值。

建议独立身份：

\[
\begin{aligned}
K_{phys}&=hash(x_0,\tau,U,T,\text{data/dynamics signature}),\\
K_{task}&=hash(K_{phys},\mathcal H,\text{mesh/numerical config},\text{parent identity}),\\
K_{eval}&=hash(K_{phys},\text{integrator/tolerances},\text{target source},\text{evaluation request}).
\end{aligned}
\tag{34}
\]

物理键不含见证计划，任务键必须包含计划、范围与自由掩码。近似分箱仅用于启发式，不能拿来命中精确物理缓存。暖恢复状态另保存源码签名与自身迭代身份，不能跨修改继续使用。

### 10.2 建议 MATLAB 接口

以下为接口规格，不是已有函数清单：

```matlab
model = v4Model(rawTargets, physicsConfig);
proposal = v4Propose(candidate, model, searchState, budget);
task = v4BuildTask(candidate, proposal, scope, purpose, config);
problem = v4Transcribe(task, model, config);
[values, jacobian, cache] = v4Evaluate(problem, z, cache);
subproblem = v4Linearize(problem, z, values, jacobian, trust);
step = v4SolveCone(subproblem, budget);
[iterate, decision] = v4AcceptStep(problem, iterate, step, budget);
controls = v4DecodeControls(problem, iterate);
[actual, trace] = v4Replay(controls, model, config, cache);
[child, feedback] = v4FinalizeTask(task, controls, actual, trace);
verified = v4VerifyFixedControls(controls, model, verifyConfig);
```

`v4Evaluate` 无排序/剪裁/重新瞄准副作用；`v4DecodeControls` 只解码。改变结构由 `v4Propose/v4BuildTask` 完成。`v4FinalizeTask` 不得仅凭优化器标志标成物理通过。

`problem.index` 至少含状态列、独立时间列、机动列、成本列、事件时间别名、机动/见证到节点映射、自由变量掩码及稀疏 Jacobian 结构。`report` 分别给 solver 状态、辅助残差、固定控制重放与独立验收状态。

### 10.3 三道不同结果判断

1. 本地候选评估：当前真实访问、初轨、全程高度、时间及原始成本；允许保存不完整和超限提案继续构造/恢复。
2. 完整独立物理验收：从原始状态独立 J2 重放，全部 35 目标距离不超过 1 km，全程高度至少 200 km，初轨与十天时限通过。超成本门槛的完整物理解也保存。
3. 搜索池/通知：`J<=6.1` 才进合格工作池/elite；真实冷启动且独立完整通过并 `J<8` 就通知用户验收。`6.1<J<8` 必须报告，但仍不进上述合格池。

罚分从不计入原始 `J`。记录配置、种子/RNG、源码与数据签名、运行路径、实际耗时；`official_alignment_verified=false` 保持，除非另有正式对齐证据。本轮不运行 ATK 或正式 24 分钟批次。

## 13. 本轮结论与后续实施判据

这套结构把“轨迹优先”落实为共同约束早期控制的多目标残差、完整动力学连接、构造中的历史回调和真实后缀重算。它给出代码应该求解的对象和各层之间的契约，不证明能在给定预算得到低于 6.1 或 8 km/s 的解。

推荐讨论后按此数值主线实施：笛卡尔六自由度初态、事件型多重打靶、精确脉冲/相遇锥、带恢复阶段的顺序凸化。主要待决定的是是否采用这条 SOCP 主线，以及窗口采样、分层预算、束容量和反馈分箱等可配置参数；A+B 和 B 的两维范围不重新列为待选。

本轮只做资料/源码阅读、公式与索引静态核对、文档归档。没有运行 MATLAB 优化、回归或冷启动批次，没有 V4 新成绩。实施时必要的定向检查应回答具体风险：导数是否与同一函数一致；零时长与零脉冲是否正确；窗口外冻结控制是否仍传播新后缀；未连接节点能否误升级；锥子问题输出是否经真实重放。通过这些检查仍不能替代完整任务的冷启动与独立验收。
