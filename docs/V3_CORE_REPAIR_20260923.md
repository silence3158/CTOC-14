# V3 核心修复：联合方向、真实连接与物理验收

## 问题判断

本轮依据用户要求，先分析核心问题，再实施。上一轮 480 秒结果见 [V3_FULL_SEARCH_RESULTS_20260923.md](V3_FULL_SEARCH_RESULTS_20260923.md)。核心不是再加种子或预算，而是当前优化子问题提出的下降方向难以转化成满足飞越条件的真实全程轨迹。

两个耦合原因：

1. 平方距离不等式 `||r-r_target||^2-rho^2<=0` 在目标中心的一阶位置梯度为零。它作为非线性约束本身没有错误，但对本项目大量中心瞄准初猜，单次线性化的 QP 不能有效限制下一步相对位置。原罚函数会将步长压得很小；单独放大步长则脱靶。
2. 多重打靶的辅助状态可以在小的局部缺陷下得到较低成本，但固定实际脉冲从头传播会放大缺陷。只在末尾回溯控制量，不能高效维持全程可行。大幅随机变异同样缺少有连接条件的候选构造。

反复重启相同精修、恢复池重复初始化和空信息素是调度问题，会加剧浪费，但不单独解释下降步的物理失败。模型仍允许自由机动、零访问弧、多目标自然弧和初轨六变量；无需收缩模型来解决这些数值问题。

## 已实现的核心闭环

完整且独立可行的有脉冲初猜默认走 `v3ProjectedJoint`：

```text
实际可行轨迹
 → 全变量多重打靶与稀疏 QP 方向
 → 三维相对位置的线性约束，避免中心梯度退化
 → 对已有脉冲逐弧进行真实状态连接修正
 → 重算修正后的实际脉冲总 ΔV
 → 固定这些脉冲独立验证全部目标与全程高度
 → 成功才更新工作轨迹，重新构建下一次联合问题
```

- `v3JointDirection` 保留初轨六变量、全部事件时间、脉冲矢量和辅助节点。使用现有 quadprog，不引入新工具箱。
- `v3ShootingProblem.encounter_linearization` 对相对位置向量线性化，以球内轴对齐盒 `±rho/sqrt(3)` 作为 QP 搜索近似。这是保守方向生成方式，会限制当前子问题的方向，不是将正式球形 1 km 条件改成盒形条件。原非线性模型和最终球形验收保留。
- `v3ConnectControls` 从真实初轨开始独立传播，在每个已有脉冲后，用变分矩阵修正出发速度以接近提案指定的下一机动位置/终点；每段接收上段真实末位置和速度。不写入目标位置、不重置节点、不增加末端交会脉冲。修正改变脉冲，必须重新计费，不能使用 QP 的辅助目标冒充成本。
- 修正失败时显式拒绝；已连接弧须通过高度检查。连接通过也不等于 35 目标全部通过，仍须完整独立验证。Newton 初猜失败时可用既有 Lambert/J2 分支生成器重新给出速度初猜，其有限分支范围仍是算法近似。
- 接受一步后重新从实际轨迹构建打靶问题，避免携带未实现的辅助状态继续下降。默认方向半径 0.005，是可配置缩放变量半径；根据接受情况改变。没有数学收敛或全局最优保证。
- `projected_joint=false` 可显式使用历史路径；不完整候选和无脉冲案例继续走原恢复路径。本轮不是把所有恢复问题都替换成新的完整解精修器。

## 有连接条件的变异及调度

`v3ConnectedMutation` 保留原来的机动插入、删除、移动、初轨改变等提案，再用原轨迹提供连接位置参考，修正真实脉冲；参考位置只是该次提案的构造条件，后续完整联合优化重新释放全部变量。访问见证重分配这种不改变物理轨迹的随机提案，在工作池变异中改为初轨提案。

大幅初轨提案失败时，沿原初轨到提案的方向尝试 0.3、0.1、0.03 比例，记录失败和接受比例；这不证明任意大幅变异都能恢复，也不是永久限制初轨自由度。

搜索器进一步修复：

- 已精修过的相同完整物理输入不再从头执行同样的 work/joint_refine，而改为连接式变异。物理表发生变化后的精修仍允许。
- 初始候选只进入 pending_initial，不同时复制到恢复池。
- 原轨迹保底不计新增 accepted；零成本差不用于 SA 温度样本。
- 把已独立验证的完整轨迹转成与构造器一致的状态—动作键，按完整任务实际成本反馈信息素；初始完整解也可提供经验。同一物理轨迹只沉积一次，不要求每次必须刷新历史精英。部分路径成本不参与完整任务奖励。

## 针对性实测

### 完整任务局部联合下降

起点 warm_repair_01：35/35，17.814617165682 km/s。

先只加入真实连接、尚未加入相对位置向量约束的 60 秒诊断仍失败：0.005 半径全步连接成功，但所有目标均未被确认有效飞越，最大检出最近距离约 319 km。它说明“连接连续”本身不等于“完成访问”，不能单独作为修复完成标准。

加入向量约束后，同一起点 60 秒开发检查（实际 60.014 s）接受两步：

| 状态 | 实际总 ΔV km/s | 全目标最大检出最近距离 km |
|---|---:|---:|
| 初始 | 17.814617165682 | 约 0.043 |
| 接受第 1 步 | 17.794456392474 | 0.302807320 |
| 接受第 2 步 | **17.766587256903** | **0.511843815** |

两步均经固定原脉冲独立 J2 验证，35/35 且高度通过，净下降 **48.0299088 m/s**。较大步因 1.0278/1.0825 km 脱靶被拒绝，0.3 比例步通过；没有放宽 1 km 门槛。最后一条提案因连接预算用尽被拒绝。

产物 `runs/v3/development/core_repair_check.mat`，日志 `core_repair_check_vector.log`；初版失败日志 `core_repair_check.log`。这些是开发检查，不是 480 秒用户实验。

### 搜索集成检查

`v3_core_repair_120_01`：实际 128.830 s，软超时 8.830 s；2 次联合调用均产生新的完整下降，17.794456392474 → **17.775425755687 km/s**；工作池 3 条不同物理轨迹，信息素 62 个键。验证了真实下降和学习反馈接入搜索。该运行使用当时源码；后续又增加初轨连续化、提前高度拒绝、独立传播近奇点拒绝和去除重复恢复入口，不能拿该检查点恢复最终源码。

### 变异的失败证据

seed 101 的完整大幅初轨改动约为 RAAN -1.285 rad、相位 -1.428 rad。初次连接失败，Lambert 重新播种的 3 个候选均被深穿地球筛选拒绝。0.3 比例版本虽然连接成功并访问 35/35，但全程高度不通过；因此不能称完整可行变异。随后将每段高度检查前移至连接修正过程，使连续化可继续尝试更小比例。这些失败不删除、不冒充 SA 成功。

## 验收范围与后续

本轮只运行必要的 60/90/120 秒开发检查及回归，不代跑正式 480 秒实验。较好初解的局部下降不等于从头全局发现能力已经解决，仍未达到约 6 km/s 的外部竞争参考。信息素有记录也不等于已经证明蚁群提升成绩。全部成绩仍为 nominal J2，未与竞赛引擎坐标和未来地球定向正式对齐，未启动 ATK 或提交。
