## 3. 完整自由机动模型

### 3.1 输入与初始条件

目标入口 `data/ctoc14b_targets.csv`，原场景 `D:\CTOC-14\problem\ctoc14乙题\CTOC14B.atk`，不修改原始资料。历元 UTC 2035-01-01 12:00:00，内部单位 km、s、rad、km/s，坐标转换显式处理。

初轨保留六自由度，可用 `q0=[a0,ec0,es0,i0,Omega0,u0]`：

```text
RE+590 <= a0 <= RE+610 km
ec0=e0*cos(omega0), es0=e0*sin(omega0)
ec0^2+es0^2 < 1e-6
u0=omega0+nu0
0 <= i0 <= pi; Omega0、u0 为周期角
```

允许等价非奇异编码，不固定 600 km 圆轨道；严格偏心率上界的数值内缩另记。

### 3.2 决策与统一目标

```text
X = (q0,T,M,{tau[k],dv[k]}[k=1:M],{theta[j]}[j=1:35])
M 为任意非负有限整数
0 <= tau[1] < ... < tau[M] <= T <= 864000 s
0 <= theta[j] <= T
J(X) = sum(norm(dv[k]))
```

`theta[j]` 是一个有效访问见证，不要求为首次接近时刻。目标顺序是轨迹事件的结果，不预设排列、不预设每个目标属于哪条机动弧。无终端速度约束、返航要求、单脉冲上限、相对飞越速度上限或正式脉冲次数上限。

数学问题是在所有有限 M 的可行集合并集上求 J 的下确界；不预先宣称有限次数最优解一定存在。程序中的最大活动脉冲数和候选幅值范围只能是可扩展的搜索近似，必须记录并安排扩展，不能以固定 35 个槽位代表完整模型。

### 3.3 摄动动力学与脉冲

```text
x=(r,v)
dr/dt=v
dv/dt=-mu*r/|r|^3 + a_J2(r,t)
r(tau+)=r(tau-)
v(tau+)=v(tau-)+dv[k]
```

巡检器、全部目标、初始滑行和中间滑行采用一致的中心引力加 J2 模型。参数、系数归一化、轴方向、参考系和时间转换须与竞赛版 ATK/EGM96 核对；不将未经核对的常数或 J2 平均根数传播作为最终模型。不增加大气阻力、三体等其他摄动力。

机动位置由真实轨迹 `r(tau[k])` 决定，允许自由变化但不能瞬移。飞越不改变位置、速度，也不触发必需脉冲。同刻脉冲先矢量合并再计费，零脉冲可移除；末端机动不强制存在。

允许初始多次过渡机动、访问后延迟机动、连续多个零访问弧、一弧多目标、首次机动前访问、多圈传播和机动/访问同刻。自然传播无需围绕固定不变的二体椭圆；J2 下按真实无推力轨迹演化。无模型层最短事件间隔、圈数上限或局部等待窗口。

### 3.4 全任务约束

对全部 j 存在 theta[j] 满足 `norm(r(theta[j])-r_target[j](theta[j]))<=1 km`。重复接近只计一次，允许同刻访问不同目标。全过程最低高度必须满足正式 200 km 口径，包含各弧内部、初始滑行和机动边界；本地径向高度口径与正式验证口径的对齐须记录。

初轨、时间、动力学连接、目标距离与路径高度约束共同构成一个优化问题。不把先选定的序列、片段入口/出口或初轨永久锁死，不把片段成本代替 J。访问和机动排序可以在一次局部数值求解中采用固定事件拓扑，但外层必须可重排、插入、删除和重新分配访问区间。

## 5. 状态驱动的集束蚁群

### 5.1 广域初始化

同时采样合法初轨、首次机动时间、早期脉冲/滑行和不同首目标或首片段。覆盖轨道面方向、相位和时间尺度，混合物理引导与无目标绑定试射；不能只随机排列后套入相同出发轨迹。当前从头搜索不加载 V1/V2/V3 历史精英或轨迹；根节点依据原始目标及其星历重新生成。历史解导入接口仅供用户以后明确要求的热启动或历史对照，启用时仍须在 J2 下重新验证，不能直接继承旧成绩。

归档实际初轨、顺序、机动时序和轨迹特征差异；新 RNG 不等于新区域。不只按首脉冲最小筛选根节点，保留不同未来连接潜力。

### 5.2 节点与扩展

节点保存 `(t,r,v,visited_mask,J,prefix)`。扩展包括自由滑行、滑行后脉冲、目标引导脉冲、多个零访问过渡步骤及多目标自然弧。访问通过真实传播与事件检测确定；目标序列只能作为提案标签。

对连续动作进行多尺度采样并修正，覆盖不同传播时长、机动方向/幅值和多圈机会。数值不可能枚举全部连续动作，但不得只提供固定访问模板。允许短前缀修正帮助构造；前缀是初始化，不应在完整任务联合优化时保持不可变。

束的分组同时考虑访问集合/覆盖进度、绝对时刻、末端轨道几何和速度状态。不把机动数、访问数和扩展层数混为一谈；给零访问过渡路径保留预算，控制无效循环但不按零访问直接拒绝。分组、束宽、过渡扩展配额是启发式，须可扩展并记录。

排序采用已耗成本加剩余任务估价，并结合快速补全和多样性保留。未经证明的估价不是严格下界，不能声称安全排除了最优解。较早到达并不严格支配较晚到达；J2、多圈与目标相位都依赖绝对时间。

### 5.3 信息素

采用带状态条件的经验 `Phi(features(s),action)`，不以固定 35×35 卫星边权替代动力学。特征可包含时间区间、轨道几何、速度特征、访问上下文；动作标签包含目标引导、过渡、滑行尺度与机动类型。离散标签只指导连续候选采样，不构成永久动作限制。

```text
proposal_probability(a|s) ∝ Phi(s,a)^alpha * eta(s,a)^beta
```

保留非零无经验探索份额，使用挥发与有界强化防止单一路径垄断。主要依据完成并通过统一验证的全任务成本回传经验；局部零成本或访问数增加不能代替最终收益。过渡步骤可从所在成功完整任务得到贡献反馈。分箱、挥发率、权重、更新时间和候选池均在实际配置中保存，不预设为已验证最优值。

## 6. 统一摄动联合优化内核

采用稀疏多重打靶作为首版数值架构。固定一次活动拓扑时，联合优化初轨、全部机动时刻/矢量、T、全部访问见证以及必要辅助节点。相邻节点通过 J2 积分的动力学缺陷等式连接；高度、距离和初轨约束进入同一个问题。稀疏分块是计算结构，不是局部成本拼接。

允许先做约束恢复再优化 J，但恢复中产生的罚值不得当作可行 ΔV。模长零点可采用辅助代价变量 `s[k]>=norm(dv[k])`，最小化 sum(s)，最终重算真实模长和。求解器选择、许可、梯度接口在实施前核验；可考察 solver-based fmincon SQP/内点方法，不提前宣称某方法速度最优。

事件拓扑包含机动与访问的相对次序。允许通过外层事件移位/重排及重新建立打靶节点改变它；不能把目标永久绑定到某个机动区间。机动/访问同刻、近零自然弧需专门处理，不设置未经标注的固定 30 s 下界。即使使用有限网格，高度和飞越最终仍需连续时间验证。

J2 下不把二体 Lambert 分支作为全部解的边界。Lambert 解可以提供初猜，真实轨迹须通过摄动连接修正；多圈及其他区域须能通过时长、状态和脉冲扰动生成。

## 7. 大幅轨迹变异与 SA

首版同时实现机动插入/删除/合并、机动时刻远距离移动、零访问过渡链重构、多圈滑行改变、目标访问事件重排/重新分配区间、初轨大幅改变并重建前段，以及整段删除重建。移动时间或改变初轨必须重新传播和联合修复全任务，不能保留失效后缀成本。

变异后先进入统一约束恢复与联合优化。完整可行候选使用 SA：

```text
accept = true                              if Jnew <= Jcurrent
accept with exp(-(Jnew-Jcurrent)/Theta)     otherwise
```

Theta 与成本差同量纲或使用一致归一化；根据实际可行扰动成本差定标，记录冷却、停滞升温、重启和随机决策。SA 允许完整可行工作解暂时更贵，历史最好解不下降。不可行候选另入恢复池，不混用罚值做可行 SA 比较。

工作解来自多种不同结构，不只从当前冠军附近变异；变异得到的新状态/方案可反馈束的初始化及完整候选池，必须按新的真实入口重建。明确区分标准单调 basin hopping 和这里的可上坡 SA 接受，不混称。

## 8. 加速与算力组织

- 缓存全部目标的 J2 星历，插值只在误差可控的评价层使用；复核采用独立可靠传播。候选快速筛查可用更廉价近似，但其结果不能被标记为 J2 可行。
- 研究传播的状态转移矩阵、变分方程与稀疏导数，减少全变量有限差分；导数需数值核验，不把错误梯度换来的速度当作收益。
- 采用粗筛、短预算恢复、联合精修、独立验证的分级计算；分级不改变同一个物理模型和最终目标。缓存按入口状态/时间和模型签名匹配，近邻只用于初猜。
- 低质量候选及时终止，避免对每个扩展都做完整长时间优化；对尚未显露收益的轨迹区域保留最低探索预算。
- 外层任务并行，避免嵌套过量并行。无并行工具箱保留同算法串行；目标缓存可共享，工作状态和 RNG 独立。
- 候选交换兼顾成本与不同初轨/时间/机动结构，交换周期计入开销。自适应算力依据已验证改善、新颖可行候选和耗时，保持机制最低份额；不以一次失败就永久关闭某机制。

不在本次文档中把束宽、温度、脉冲上限或种子数写死为有效参数。实施配置必须完整暴露这些搜索近似及扩展规则，实际运行前记录预算、软件版本和源码签名。

## 9. 完整首版运行闭环

```text
加载数据与核验 J2/参考系 → 初始化目标星历和多样化根节点
循环至用户预算/停止条件：
    集束蚁群扩展：自由动作、零访问、多圈与目标引导共同参与
    候选筛查、状态多样性保留、快速补全
    完整候选进入统一 J2 恢复与全任务联合优化
    完整工作池执行大幅变异 → 同一联合优化器 → SA 接受
    固定原脉冲独立复核候选，更新导出精英
    回传信息素，交换少量多样性候选，调整预算/重启
    保存检查点、耗时、配置、随机状态与失败记录
```
