## 1. 版本定位与依据

用户要求围绕“先试射一条自然飞行弧，发现可能连续飞越的目标组合，再微调与重新规划”重新建模，继续采用简单动力学，不上摄动。

V2 将机动事件与访问事件解耦：机动可以发生在两个访问事件之间，访问之后可以自然滑行再机动；一次机动之后的自然飞行弧可以包含零个、一个或多个目标访问。零访问弧允许作为调相或过渡弧，但不能虚增访问数。所有规划均为已知目标初始状态下的离线预测与优化，不是假设实际飞行后才获得目标信息。

- 正式物理条件、数据来源及未来交付要求继承 [MODEL.md](MODEL.md)。该文件保留为 V1 历史模型。
- 当前 V2 轨迹结构、变量和搜索设计以本文为准；V1 的固定 35 段、42 个连续变量和访问事件绑定机动的约定不再限制 V2。
- 方法参考：`../literature/面向大规模目标访问任务的飞行序列规划方法_朱阅訸(1).pdf`，第 6.3 节（片段微调）和第 6.4 节（试射、微调及片段拼接），重点为印刷页 113、117–120。
- 只借鉴方法，不引入论文中的脉冲上限、相对飞越速度上限或事件最小间隔等本题没有的约束。
- 编程语言仍为 MATLAB，采用 `+ctocscreen` 包、`double`、MAT 状态与检查点。不启动 ATK，不使用 J2、平均摄动或其他摄动力。

本文中的搜索窗口、脉冲采样范围、片段模板、圈数、束宽和计算预算均为可配置算法近似，既不是赛题限制，也不是已经测得的有效配置。

## 2. 不变的任务与动力学

一艘巡检飞行器，在从固定历元开始的 864000 s 内，有效飞越全部 35 颗目标，最小化实际执行脉冲的模长之和。当前阶段不计算 B，不用飞行耗时替代 B，不将脉冲次数作为第二目标，也不采用 ΔV—耗时 Pareto 目标。

正式评分仍按访问数优先、同访问数比较 F2；本地完整解只比较满足全部约束且访问数为 35 的总 ΔV。部分路径只作搜索状态，不与完整可行解混排。

固定输入与单位：

| 项目 | 约定 |
|---|---|
| 目标数据 | `data/ctoc14b_targets.csv`，35 个唯一目标，使用笛卡尔初始状态 |
| 原始依据 | `D:\CTOC-14\problem\ctoc14乙题\CTOC14B.atk`，保持不变 |
| 初始历元 | UTC 2035-01-01 12:00:00 |
| 内部单位 | km、s、rad、km/s；时间为距初始历元的秒 |
| 参数 | 从已核验 EGM96 来源继承，当前 mu = 398600.4415 km³/s²，RE = 6378.1363 km |
| 坐标 | 继承输入审计记录中的原场景惯性坐标表达，不未经核验改标为 J2000/ICRF |
| 有效访问 | 实际距离 <= 1 km，同一目标只计一次 |
| 最低高度 | 从历元到任务结束全过程 `norm(r)-RE >= 200 km`，当前二体检查口径 |

飞行器、目标及全部初始/中间滑行统一使用：

```text
dr/dt = v
dv/dt = -mu*r/norm(r)^3
```

初始轨道继续保留完整 6 个自由度：

```text
q0 = [a0, ec0, es0, i0, Omega0, u0]
RE+590 <= a0 <= RE+610
ec0^2 + es0^2 < 1e-6
0 <= i0 <= pi
Omega0、u0 为周期角；ec0=e0*cos(omega0)，es0=e0*sin(omega0)
```

严格偏心率上界的数值内缩必须记录；圆轨道、赤道轨道的角度退化处理继承经过验证的转换规范。不能将初轨固定为 600 km 圆轨道代替完整模型。

## 3. 机动与访问解耦的数学模型

### 3.1 轨迹决策变量

对一个固定机动拓扑，采用直接脉冲表示：

```text
X = (q0, M, tau[1:M], u[1:M,1:3], T)
0 <= tau[1] < ... < tau[M] < T <= 864000
u[m] = 第 m 次真实脉冲矢量，单位 km/s
J(X) = sum(norm(u[m]))
```

M 为非负整数，由片段组合或机动插入/删除决定，不固定为 35。上述严格排序是合并同刻脉冲后的规范形式：同一时刻的脉冲必须先矢量相加再计费；零脉冲可以从执行表移除。不得用分拆脉冲或标量相减制造虚假节省。

初始滑行为 `[0,tau[1]]`；允许首脉冲在 0 时刻。任务结束无需额外机动；T 是自由结束时刻，完整轨迹可在全部目标首次有效访问均发生后截断，通常取最晚首次访问时刻。T 不是独立于传播时间表的另一份飞行时长。固定 M 时，该直接表示有 6+4M+1 个连续变量；事件时间及多重打靶节点是求解辅助量，不应与物理自由度混淆。

状态连续与脉冲跳变：

```text
r(tau[m]+) = r(tau[m]-)
v(tau[m]+) = v(tau[m]-) + u[m]
```

除真实脉冲外，全轨迹连续传播。飞越事件不会改变位置或速度；不能置为目标状态。自然滑行不是 ATK 的“保持段”，本阶段也不创建 ATK 场景。

### 3.2 访问事件与正式可行性

每颗目标 j 必须存在至少一个时刻 theta[j]：

```text
0 <= theta[j] <= T
norm(r_inspector(theta[j])-r_target[j](theta[j])) <= 1 km
```

访问顺序是这些事件的结果，可作为搜索中的离散辅助变量，但不强制一弧一个目标。允许同一时刻访问不同目标，只要实际距离均合格；同一目标的重复接近仅计一次。初始滑行中的有效访问同样计数。

最终评价对全部目标进行事件检查，不以计划列表或片段标签证明完成数。轨迹有限、传播成功、初轨合法、全程高度合格、时间合格、35 个真实访问缺一不可。失败返回明确状态，不以有限罚值充当可行成本。

### 3.3 实用的分层编码

不直接让一个高维混合优化器同时盲搜 M、所有脉冲和全部组合。外层搜索片段拓扑、目标组合和机动增删，内层在固定拓扑与分支下优化连续变量。直接脉冲时间表是统一的执行及验证格式；Lambert、多重打靶和片段局部变量只是生成该时间表的方法。

V1 候选可无损映射：初轨不变，将每段段首时刻和实际脉冲写入执行表，所有访问保留为事件。必须检查转换前后成本、状态、时间与访问一致性。V1 是 V2 的可行子集，旧的独立复核精英保留作基线。

## 4. 片段定义与接口

片段从真实入口状态 `(t_in,x_in,visited_mask)` 出发，含若干自然弧、脉冲及访问事件，返回真实出口 `(t_out,x_out)`。片段边界不必是目标访问时刻，边界本身也不自动发生脉冲。

起步模板如下，均允许入口后先滑行再施加首脉冲：

| 模板 | 含义 | 用途 |
|---|---|---|
| Coast | 不施加脉冲的有限自然弧 | 延迟机动、调相、识别自然访问 |
| S1 | 一次脉冲后的自然弧飞越一个目标 | 普通连接和构造保底 |
| S2 | 一次脉冲后的同一自然弧先后飞越两个目标 | 首先实现的“一石二鸟” |
| D3 | 两次脉冲组成的片段飞越三个目标，机动与访问相对位置由明确模板确定 | 后续扩展，包括两次机动后同一弧连续飞越三目标的论文型模板 |

模板仅限定一次局部搜索。不得把所有片段强制为 S2，或为追求低机动次数拒绝总 ΔV 更小的普通片段。每个模板明确脉冲/访问事件的排序，不能在内层迭代中无记录地切换拓扑。

建议 MATLAB 结构（接口设计，不是已有功能）：

```text
FragmentRequest:
  schema_version, dynamics_id, t_in_s, state_in[1,6], visited_mask
  remaining_time_s, target_pool, template, search_windows, seed
FragmentResult:
  status, template, maneuver_times_s[K,1], delta_v_km_s[K,3]
  event_target_ids, event_times_s, event_distances_km
  t_out_s, state_out[1,6], visited_mask_out, total_dv_km_s
  min_altitude_km, residuals, branch_refs, solver_diagnostics
  input_hash, source_hash, config, validation_level
```

缓存片段依赖完整入口时间、位置、速度及目标集合。近邻缓存仅能提供初猜，不得把别的入口对应的片段直接当作可拼接边。拼接时检查同一边界脉冲只计一次，不允许状态重置。

## 5. 试射：先发现自然弧适合访问的目标组合

1. 选择入口：来自当前束搜索节点、V1/V2 精英的真实状态，或合法初轨的新样本。
2. 采样入口滑行时长、试射脉冲及后续弧时长；先检查时间和整弧高度。
3. 传播飞行器，并与尚未访问目标在同一时间轴上比较，寻找最近接近时刻及距离。
4. 将距离低于候选门限 `d_gate_km` 的事件按时间排列，生成 S2/D3 等目标组合。
5. 将有希望的组合送入微调；失败继续试射，不能把候选门限内接近当成有效访问。

使用混合种子：精英弧扰动、Lambert 指向一个目标后继续自然传播寻找第二目标、较宽范围的脉冲和初轨随机试射。记录各类比例，保留全局探索。脉冲方向可按局部轨道坐标采样后显式转到惯性系；幅值和时间使用多尺度窗口，边界命中频繁时扩大窗口。零脉冲也应作为候选。

候选筛查可以使用粗网格与局部极小值精修，但不能用其证明没有遗漏。推荐对相对距离平方使用导数 `g(t)=(rI-rj) dot (vI-vj)` 辅助定位驻点，覆盖弧端点、脉冲边界、同号端点内的潜在极小值和掠过事件；仅检查根的符号变化不充分。

星历插值只用于粗筛，并记录误差及加宽门限；微调和验证使用真实传播。两个目标分别“靠近某条轨道”并不够，必须在各自运动到正确位置的时刻接近。

## 6. 微调：片段可行性与成本优化分开

### 6.1 S2 直接打靶

给定入口状态、目标 A/B 及访问顺序，局部变量可取：

```text
z = [w, ux, uy, uz, dA, dAB]
w >= 0; dA > 0; dAB > 0
x_burn_minus = propagate(x_in,w)
x_burn_plus  = x_burn_minus + [0,0,0,ux,uy,uz]
xA = propagate(x_burn_plus,dA)
xB = propagate(xA,dAB)       # A 处严格没有脉冲
tA = t_in+w+dA
tB = tA+dAB
```

先利用位置残差寻找可行初猜，再在实际飞越不等式与高度、时间约束下最小化脉冲/连接总成本。瞄准目标中心是初始化方式，不是把正式 1 km 门限改为零；固定入口下严格中心命中解可能孤立，不能保证一定存在。

残差用明确的位置尺度无量纲化。`lsqnonlin` 可用于带边界的位置残差初猜，不能将其残差下降视为高度及其他非线性约束已满足。后续使用带非线性约束的连续优化，或在可行性阶段直接采用约束优化。

### 6.2 与论文等价的 Lambert 连续性路线

另一路线以两段 Lambert 弧连接到 A、B，优化时刻和分支，使：

```text
c_v = v_depart(A->B) - v_arrive(start->A) -> 0
```

这等价于论文中间两个交会过渡脉冲的矢量和趋零，不需要真的执行交会匹配。保持分支在一次连续优化内固定；跨分支比较放到外层。

有限的 `norm(c_v)` 小不等于可以删掉脉冲。必须将 A 处脉冲明确置零，重新传播到 B 并检查距离、高度和后续衔接，才可标记为单脉冲双目标。若保留小修正能降低全程成本，可作为普通多脉冲候选保留，不能冒充 S2。

### 6.3 求解器与零脉冲处理

固定拓扑下是非凸连续约束优化，外层组合搜索不承诺全局最优。沿用现有数值传播及扁平变量布局时可使用 solver-based 接口，以便复用评价、预算与检查点；实现前在本机核验 `optimoptions` 和所需工具箱许可，不在设计中猜测版本选项。

零附近的脉冲模长不可微。可用辅助变量 s 和约束 `norm(u)<=s` 的等价成本表示，或使用记录参数的平滑近似生成候选；若用平方约束需同时约束 s>=0，并关注零点约束退化。最终成本始终重算真实 `sum(norm(u))`。删除脉冲作为显式外层算子，不靠浮点数“足够小”直接修改执行表。

每次记录初猜可评价性、exitflag、输出诊断、最大约束违反和真实传播结果。优化器报告收敛不是可行证明；未收敛但经独立验证合格的候选可以保留，状态需分别记录。

## 7. 全任务搜索与重新规划

采用多起点束搜索加局部破坏—重建。节点至少包含当前绝对时间、真实状态、已访问集合、累计成本、完整前缀及随机状态。

- 扩展：从每个节点生成多种 S1/S2/Coast，后续加入 D3。只增加实际确认的新访问。
- 多样性：按已访问集合、末端时间、轨道面和末端速度等分桶，保留不同未来连接潜力；相近节点间的剪枝是启发式，不能声称严格支配。
- 不以“片段 ΔV/访问数最低”作为唯一选择，也不能只比较已访问集合相同节点的当前成本而忽略末状态。
- V1 精英作为完整保底。抽取连续 2–6 个目标的局部区段，允许目标重排、合并片段、移动机动时刻、删除或插入机动，并重优化连接。
- 重新规划入口之前的前缀保持原样时，入口状态固定；需要改变前缀时，将受影响变量纳入同一个联合优化。
- 新片段若不能精确接回原后缀的时间与完整状态，必须重建或重优化后缀。禁止只把新末端位置拼到旧速度，或沿用已经失效的后缀成本。
- 产生完整解后联合精修初轨、所有机动及访问时间辅助变量，重新检测全部目标事件。

S2 只减少局部机动不一定降低总 ΔV。接受收益以完整任务独立复核后的差值为准。M 的计算上限可用于实验控制，须保存配置并做扩展敏感性试验；不能写成题目最多允许多少次机动。

## 8. 二体验证与事件判定

验证分层：`proposal`（试射候选）、`fragment_screened`（局部片段检查）、`trajectory_screened`（全程搜索传播检查）、`two_body_independent_verified`（独立固定脉冲连续积分）。只有最后一层完整 35 访问解可进入 V2 的导出精英档案。任何层级均不代表 J2 或 ATK 验证。

独立验证从原始初轨开始，用独立数值积分连续执行固定脉冲时间表；目标也独立传播。不得重新求 Lambert、重新瞄准或修补任何状态。脉冲时刻切分积分，保存脉冲前后状态。积分容差以位置/速度尺度和步长敏感性试验确定，不把某个容差值视为自动误差保证。

对每颗目标：至少提供一个独立积分确认距离 <=1 km 的有效时刻作为访问见证；最小距离定位与首次进入 1 km 球的时刻分开记录。检查所有目标、全部自然弧、初始滑行、脉冲时刻和结束时刻。自适应细分配合局部极值/门限根定位；切触且不穿越门限的事件也需处理。若声称某区间无接近事件，应有保守界或充分的区间排除依据，不能只凭粗网格无命中。

高度继续使用二体有限弧解析极值检查（含椭圆、双曲及近抛物情形），在每个独立积分边界状态上复算；初始滑行也包含在内。数值边界附近收紧搜索裕度并提升复核精度；不能仅用采样点最低高度通过。

重新执行不带中间脉冲的真实自然弧是验证“一石多鸟”的必要步骤。片段验证只说明该入口下的局部可行性，完整访问数和总代价必须在全程重放后确认。

## 10. 仿真与对照实验方案

### 10.1 实施阶段

| 阶段 | 实验内容 | 通过条件 |
|---|---|---|
| A：兼容与验证 | 转换 V1 精英、按固定脉冲表重放 | 初轨、时间、脉冲和成本一致，独立访问与高度仍合格 |
| B：事件与片段内核 | 合成已知单脉冲双目标例、近失例、同刻/边界/重复事件、零访问弧、段中低高度例 | 找到已知访问，拒绝近失及非法弧，状态连续且无重复计数 |
| C：真实目标片段试验 | 从真实数据和多个入口试射并微调 S2，对比纯随机与目标引导试射 | 输出真实可行片段，报告试射命中率、微调成功率及成本/耗时；失败也如实记录 |
| D：完整任务闭环 | S1/S2 束搜索及 V1 局部片段重构 | 导出满足全部条件的 35 访问独立复核解；无改进也保留旧基线 |
| E：大批次对照 | 新旧算法及消融实验采用相同计算预算 | 用跨种子结果判断收益，不以单条漂亮片段证明算法有效 |
| F：扩大范围 | D3、更多机动拓扑、更大时间/脉冲窗口、分支上限 | 仅在前述闭环正确后推进，记录新增复杂度与收益 |

合成案例可从合法已知弧反向构造目标初态，仅用于测试，必须与真实竞赛数据分目录保存，禁止改动原始 35 目标。

### 10.2 起步计算配置（建议，尚未执行）

| 配置 | 起步设置 | 目的 |
|---|---|---|
| smoke | 1 任务，60 s 搜索预算 | 检查状态和输出闭环，不要求求出新全访问解 |

这里是后续实验设计，不表示本次已经启动这些任务。搜索预算、独立复核耗时和总墙钟时间分别记录；同时记录 CPU/worker-seconds 和评价调用数，防止并行程度不同造成不公平比较。

必要消融：V1 同预算继续搜索；仅 S1 的 V2 自由机动时刻；S1+S2；S1+S2 加目标引导试射；后续再加入 D3。使用相同目标、同一初始精英库和同一组种子编号，记录各算法不同的随机消费序列，不声称轨迹样本逐个相同。禁止将随机试射、放开机动时刻和片段微调的收益混为一个未经区分的结论。

### 10.3 指标与报告

- 主要指标：独立复核的 35 目标完整解最小总 ΔV，以及各种子的中位数、范围、完整解成功率和随时间曲线。
- 诊断指标：试射候选率、S2/D3 微调及重放成功率、每次成功的调用数/耗时、片段回接成功率、最终净节省、失败分类。
- 结构指标：真实脉冲数、各自然弧实际访问数、初始与中间滑行时长、剩余时间；这些不是额外优化目标。
- 正确性指标：每目标访问见证、最大访问距离、全过程最低高度、独立传播差异、收紧积分与事件定位配置后的稳定性。
- 敏感性：候选门限、事件网格、机动数计算上限、时间窗口、脉冲采样范围、Lambert 分支集合。未搜索到片段不等于数学不可行。
