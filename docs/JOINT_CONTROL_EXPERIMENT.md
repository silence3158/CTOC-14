# 初轨与全任务连续变量联合优化：配对对照实验

日期：2026-09-21。实现入口已提供；正式实验由用户运行。此实验是完整联合路线的第一阶段，不等于任意机动拓扑下的全局优化。

## 1. 实验问题与分组

检验开放初轨和全任务时间变量，在同样计算预算下是否比固定初轨局部优化更有效。全部使用同一二体动力学、真实速度传递、35 目标、10 天和全过程高度约束，只比较原始总 ΔV。

| 组 | 初轨六变量 | 连续时间变量 | 顺序与拓扑 | 作用 |
|---|---|---|---|---|
| A | 固定 | 当前焦点前 1 后 2 弧及已有多目标弧邻域 | 固定 | 配套求解器中的局部基线 |
| B | 全部开放 | 与 A 相同的窗口规则 | 固定 | A→B 检验初轨加入局部联合的收益 |
| C | 全部开放 | 全部访问时刻、全部段首滑行时间 | 固定 | B→C 检验全任务时序联合的收益 |
| D | 全部开放 | C 的连续步骤与离散搜索交替 | 换序、分支重接、S1/S2 合并拆分 | C→D 检验现有离散算子的组合效果 |

A/B/C 使用同一新增连续优化器；A 并非把历史程序原封不动再跑一遍。每一步都重建完整轨迹，以全任务 ΔV 为目标，初轨变化影响整个后缀。脉冲由 Lambert 边值解消去，时间与初轨改变后重新计算真实矢量；不是独立把 3M 个脉冲分量全部放入 fmincon。

用户同轮确认利用题目 **距离≤1 km** 的飞越容差：各组统一放宽，不把它只开放给某组。每条自然弧最后一个目标增加 3 个笛卡尔瞄准偏移变量；A/B 只调整活动弧的偏移，C/D 连续步骤调整全部弧的偏移。中间自然访问使用实际距离不等式，不再强制命中中心。默认搜索半径 0.99 km，留 10 m 数值余量，独立判定仍严格按≤1 km。瞄准偏移影响整弧真实状态，不能通过直接重置位置实现。这是原约束内的更充分搜索，不是修改赛题模型。

A/B/C 的分支标签固定为配对起点所选的标签，禁止“分支消失后自动换一个”混入连续变量对照。标签按现有 Lambert 的几何方向、圈数分类和根侧编码，仍受该求解器覆盖范围限制。C 的时刻上下界覆盖整个任务域，但 SQP 是局部求解器，开放变量不意味着穷尽该域。

D 每轮先运行一次 C，再运行一段现有 targeted 离散搜索；允许工作解上坡、历史最好解独立保留。D 使用 S1/S2，引入零访问过渡弧、两脉冲三目标与任意多脉冲结构仍属后续工作。D 同时改变多个机制，因此只能评价组合算子包，不能单独归因于顺序、分支或合并中的某一个。

## 2. 配对、预算与可复现性

默认 **4 个起点 × 4 组 × 每组 480 s = 16 个任务，合计 128 进程分钟**。最多 4 个 MATLAB process workers；理想搜索墙钟约 32 分钟，另加 MATLAB/pool 启动、起点独立复核、I/O 和软预算超时。不能承诺精确 32 分钟结束。

起点 1 为当前 13.976837787874 km/s 精英，起点 2–4 为历史多起点批次的前三个已验证候选，具有不同顺序/初轨。入口会按当前求解器重建、核对成本未明显变化并独立复核一次；四组接收完全相同的重建后起点。实际初轨、成本和任务时间记录于 seed_manifest.csv，完整状态保存在 design.mat。最多可用 7 个起点（精英加前 6 个历史起点），不是在线随机生成新初轨。

每个起点四组使用同一 RNG seed，但因维数和算子差异，其随机消费不保证逐步相同。组间及不同波次不共享改进精英；组执行次序随起点轮换。同预算比较的是算法的实际效率，不强制相同 fmincon 迭代数。

每个连续调用默认 60 s、12000 次目标/约束共享的重建评价上限、150 次 SQP 迭代上限，以先触及者停止；60 s 是 OutputFcn 软时限，有限差分或单次传播不可中断，因此可能超时。每任务 480 s 包括任务内独立复核、离散发现和检查点开销，不包括共同种子准备与池启动。比较实际 elapsed_s，明显超时者应查诊断，不可只说“都运行了 8 分钟”。

为避免软超时偏向高维组，**主配对统计使用 budget_dv_km_s：仅计入在时限内已返回且通过独立复核的最好解**。超时后返回的更优解仍保存在 out.best 和 best_dv_km_s，但不计入本次同预算胜负；时限内最好解另存 out.budget_best。D 内部求解到外层返回才记为可用，口径保守且显式。

共同搜索近似：Lambert 圈数上限 2；事件间隔及段首至首次访问间隔下界 30 s；A/B 访问时刻窗口半径系数 0.42；搜索距离半径 0.99 km、候选与正式独立判定上限 1 km；偏心率非线性约束使用 e≤0.001×(1−1e−9) 数值裕量。以上不是正式赛题限制。C/D 连续变量数为 6+N+4M，含 N 个访问时刻、M 个等待和 3M 个瞄准偏移；当前 34 脉冲精英对应 177 个变量。

有 Optimization Toolbox 才能运行。Parallel Computing Toolbox 不可用时自动明确提示并以同算法串行。当前已核验本机 R2024a 安装这两个工具箱与 fmincon 选项。内层 UseParallel=false。现有池的 worker 数与要求不符时会报错，不擅自关闭用户现有池。

## 3. 启动

在 MATLAB 命令窗口运行：

```matlab
cd('D:\CTOC-14\simulation');
addpath('src','scripts');
folder = run_joint_control_experiment('joint_compare_01',480,4,4,'ABCD');
```

参数依次为：唯一目录标签、每任务秒数、并行 worker 数、起点数、实验组。输出目录 `runs/joint_control/joint_compare_01` 必须不存在，防止覆盖历史结果。

仅做 A/B/C 主消融、暂不运行 D：

```matlab
folder = run_joint_control_experiment('joint_abc_01',480,4,4,'ABC');
```

串行运行使用第三参数 1。如确实需要关闭已有池再建立 4 worker 池，由操作者先运行 `delete(gcp('nocreate'))`。不要在同一台机器同时启动多批实验争抢 CPU。

可选短时连通检查（不能用于判断算法胜负）：

```matlab
folder = run_joint_control_experiment('joint_smoke_user',15,1,1,'ABC');
```

完整调用返回时自动汇总。也可在运行期间或结束后，用第二个 MATLAB 会话汇总已完成任务：

```matlab
addpath('scripts');
folder = 'D:\CTOC-14\simulation\runs\joint_control\joint_compare_01';
report = report_joint_control_experiment(folder);
```

受控停止：在该目录下创建无扩展名的 STOP 文件。当前步在回调/外层边界停止并写出状态；不得强制把 stopped 当 completed。

```matlab
fid = fopen(fullfile(folder,'STOP'),'w'); fclose(fid);
```

此入口暂不提供中断任务的自动续算；checkpoint.mat 保存已有最佳解和诊断。需要完整配对时用新标签重跑整组设计，避免给部分组额外预算造成混杂。

## 4. 结果如何评估

1. **先检查 tasks.csv。** 16 行均应为 completed；每行 verified_visits=35、max_miss_m≤1000、min_altitude_km≥200。所有起点已可行，所以“最终仍可行”不等于算法产生了新解；重点同时看 gain_m_s。失败任务保留基线但不能计作已完成实验。
2. **主要看 paired.csv。** A_minus_B 为同起点 A 的成本减 B，正数表示 B 更好；B_minus_C、C_minus_D 同理。先看 complete_pairs 是否齐全，再看 median_gain_m_s、超过 1 m/s 的胜/负次数以及最小最大差值。1 m/s 只是事先固定的报告阈值，不是显著性检验。
3. **辅助看 groups.csv。** 该表同样按时限内的 budget_dv_km_s 汇总；tasks.csv 的 best_dv_km_s 额外展示含软超时阶段的最终成绩。中位数与配对差值回答“改进是否跨起点稳定”。不同起点初始质量不同，不能只凭未配对的组平均/中位成本归因。
4. **确认变量确实工作。** tasks.csv 的 scaled_q_change 为最佳解相对初轨的缩放差，A 应为 0；B/C/D 最好解没有变化不代表未开放变量，须看每个 result.mat 内 diagnostics.active_indices、exitflag、output、failure_reason 和 evaluations。零收益且全是报错，属于实现/求解问题，不是算法被证伪。
5. **检查预算和趋势。** result.mat 中 out.history 列为 elapsed_s、已独立验证的 best ΔV、累计记录到的评价数、迭代号。若 C 在终止前持续下降，可用相同新预算将所有组一同延长；不能只延长 C 再与旧 A 比较。求解器维数更高、每步成本更大，本次结果只代表给定预算表现。

评价次数字段为 continuous_and_window_evaluations：包括新连续重建与 D 内旧窗口求解器的评价，不含 D 试射/重启内部全部重建，也不含独立积分。因此它是诊断指标，不可用于宣称严格等评价预算。continuous_validation_rejects 仅统计新连续步骤，D 的拒绝与异常还需查 discrete 子目录和 diagnostics。

推荐预先采用的决策口径：4 个完整配对中至少 3 个改善超过 1 m/s，且配对中位收益为正，作为值得扩大验证的工程信号；不是统计显著性或全局优越性的证明。若收益集中在一个起点，先扩大独立起点集合。若 B 优于 A 而 C 不优于 B，优先查全变量尺度、梯度/分支可行域与预算，不能解释为“全任务联合没有价值”。D 优于 C 时再另做离散算子拆分消融。

## 5. 文件与验证层级

- `design.mat`：配对种子、问题数据、配置、任务顺序、工具箱版本、源码 hash。
- `source_snapshot/`：本次代码和实验设计快照，便于复现；原始数据与历史精英保持不变。
- `seedXX_A/` 等：result.mat、checkpoint.mat；D 另有 discrete_XXX 子目录。
- `tasks.csv`、`groups.csv`、`paired.csv`、`report.mat`、`convergence.png`：自动汇总及各起点收敛曲线；缺失和失败不删行、不伪装为完成。
- `result.mat` 的 `out.best.schedule` 与 `out.best.independent`：真正可重放的该组最好解及独立复核。未覆盖现有正式精英文件。

每次纳入更优解都用固定原脉冲独立积分，并要求快速固定脉冲重放同时通过。有限罚值只用于优化器数值处理，不写成可行成本。结果仅为二体筛选，没有 J2 或 ATK 验证。
