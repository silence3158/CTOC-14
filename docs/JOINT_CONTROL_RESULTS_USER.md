## 支持的结论与不支持的归因

1. 当前实现与预算下，自由初轨配合局部时间窗口的 B，比一次开放全任务变量的 C 更有效，尤其在较差历史起点上。下一阶段优先复用 B 的分块思路有依据。
2. **03 的 B、C 都开放初轨六变量。** 295.66 m/s 的差值说明优化组织方式的差异，不能全部归因为“开放初轨”。初轨是否开放的直接对照是 A/B，但目前只在一个起点测过，优势为不足 0.1 m/s。
3. MAT 诊断显示，03 的 B 在起点 2–4 确实改变了初轨，缩放变化范数约 1.35–1.82，而 C 约 0.0057–0.0353。这支持 B 实际推动初轨与局部变量协同调整的解释，但不是独立因果消融。
4. 03 起点 2–4 的 B 总收益分别约 1253.31、812.25、673.75 m/s，首脉冲只分别降低 14.50、58.16、7.53 m/s。因此主要收益不能解释成“仅首脉冲省油”；局部时序与后续连接同样重要。
5. 检查 03 的 B/C 诊断没有 solver failure_reason 报错；不能将 C 较弱直接说成程序异常。高维 SQP 的尺度、有限差分、分支可行域、每次 60 s 分块与预算可能影响效果，尚未分别测定。

所有归档结果记录为二体 35/35 独立复核；不是 J2 或 ATK 验证。部分飞越贴近 990 m 搜索边界，符合当前容差使用方式。

## 对下一步实验的影响

昂贵窗口结构替换的所有组统一开放初轨、首段及入口/出口邻域变量；用同一求解器和同一预算下的原结构 R 作为对照。替换组需同时优于共同起点和 R，才能认定新增结构算子在该预算下有净收益。若仅优于起点而不优于 R，收益可能主要来自继续连续精修。

正式设计与入口见 [STRUCTURE_EXPERIMENT.md](STRUCTURE_EXPERIMENT.md)。默认采用 02/seed01_B 最终已验证解做起点，另可用 03/seed02_B 等不同顺序的解检查稳健性。不同窗口来自同一任务，不能当作独立随机样本做统计显著性声明。
