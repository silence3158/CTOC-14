# V3 成本门槛与负反馈修订

本轮目标是从空历史输入搜索完整 35 目标轨迹，并执行用户指定的 6.1 km/s 接纳门槛。机制实现不等于达成目标；此前短测均未得到门槛内的完整独立合格解。最后一次验证结果见下方实测记录。

## 接纳与惩罚

- 原始成本始终为实际脉冲向量模长之和。总 ΔV > 6.1 km/s 的输出不得进入合格工作池、SA 或 `elite.mat`；保存拒绝原因。若完整独立物理验证通过但成本超限，另存 `rejected_complete.mat`，不能算合格成绩。
- 倾角由真实脉冲前后 `cross(r,v)` 求取。令 `p_i=(max(0,abs(i_after-i_before)-5)/5)^2`；构造排序加 `0.5*p_i`。完整轨道面法向夹角另记，不能与倾角差混淆。这不是固定所有目标或飞行器共面。
- J2 修正后的实际动作提供负反馈；积分失败、预算耗尽和 Lambert 估价不能充当不可达证据。完整超限轨迹的超额代价按各机动实际耗油分配；倾角惩罚也适用于部分路径。
- 负反馈独立于正奖励保存。查询权重为 `max(0.05, positive/(1+negative))`，负值累积上限为 4，按每轮 0.1 挥发。相同实际动作观察去重，避免反复读取同一结果加罚。细状态键保留；粗状态键只作可遗忘的经验推广，不代表动力学等价。
- 为提供重建初猜，部分轨迹允许进入默认 61 km/s 的可配置提案包络；**这不是把最终门槛改为 61**。超限前缀无正奖励，不能靠继续滑行“退还”已耗 ΔV，只能改变之前的机动来降低成本。
- 联合求解器仍优化真实 ΔV。倾角罚分用于构造排序与信息素反馈，不混入成绩；完整独立验收仍检查全部 35 目标、1 km、200 km、10 天和初轨条件。未做 ATK，正式对齐仍为 false。

## 调度与构造改动

1. 工作算子按谱系轮转精修、定向重建、变异。精修输出换了数值键，不再重置精修优先权。同谱系/访问顺序/机动数的工作代表设配额，完整奖励只承认该族的新成本改善。
2. 首个完整工作解不再关闭其他初轨的覆盖补全。超限前缀进入全部 35 目标恢复；先补齐结构再联合求解。超限完整候选不能只做一次验证后跳过优化。
3. 时间候选加入当前轨道面的穿越窗口，用 Lambert 出发脉冲估价并交给真实 J2 打靶。到达速度不重置为目标速度。时间枚举交错中、长、短时长，减少墙钟截止始终留下短时长的偏差。
4. 保留低倾角初轨提案和其他几何/随机初轨；加入实际平面内的轨道形状过渡机动，允许零访问弧。这些均为搜索启发式，并未证明其平均收益。
5. 修正自由机动负反馈写入/查询键不一致；前缀截短后从已有传播状态重算倾角罚分；计入末端机动；避免新增一遍传播来计算这些罚分。

以上第一轮检查点接口为 `free_maneuver_search_v3_9`。用户随后要求继续降成本，第二轮更新为 `free_maneuver_search_v3_10`，仍严格检查源码签名。不得加载旧检查点绕过变更检测。

第二轮加入从真实 J2 自然滑行求取的最近接近时间窗口；枚举仅用筛选预算的 0.65，为时间精修保留机会；按剩余目标轨道周期分配软时间份额，时间惩罚权重改为 0.3；束内优先保留成本仍不超限的前缀。这些都是构造引导，未改变正式任务条件。用户在本轮结束前要求收尾暂停，交接见 [V3_PAUSE_HANDOFF_20260924.md](V3_PAUSE_HANDOFF_20260924.md)。

## 方法依据

- [Beam P-ACO 论文](https://arxiv.org/abs/1704.00702)及[作者实现](https://github.com/lfsimoes/beam_paco__gtoc5)，核对提交 `0075a8aa211435cdfe0bdd559dc2f88cbdf655fa` 的 `paco/paco.py`、`paco_traj.py`、`gtoc5/gtoc5.py`：有限种群贡献、淘汰撤销贡献、状态依赖转移。未导入其现成发射解库、质量或交会速度条件。
- 用户提供 CEA，DOI [10.1145/3712256.3726321](https://doi.org/10.1145/3712256.3726321)：借鉴 TAS/SRS 的尾部追加与重建，以及按实际结果更新搜索经验。没有声称当前实现完全复现论文。
- [ACOTSP 源码](https://github.com/epid/ACOTSP)，核对提交 `4eb233f9ddfe92c0d4e22c7752036578ffb09476` 的 `ants.c`，尤其 `bwas_worst_ant_update` 和 `check_pheromone_trail_limits`：坏路径差异化衰减、有界信息素。当前独立负反馈表是针对状态连续变化的改编，**不是原样 BWAS，也不是神经强化学习**。
- 本地 `beamsearch/bsBeamConstruct.m` 及 README 对截断候选时刻造成高成本的历史说明，也用于核查枚举偏差；没有读取其历史解作为输入。
