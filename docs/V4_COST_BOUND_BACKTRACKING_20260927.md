# V4 思路备忘：成本阈值、完整试走与逐级回溯

日期：2026-09-27。

状态：用户认可讨论方向并要求先归档。本文件是后续求解设计依据，不代表已接入正式求解器，也不授权恢复算法开发或搜索。保持暂停。正式物理模型、6.1 km/s 合格池门槛及 8 km/s 通知验收线不变。

## 1. 要解决的问题

目前穿越点构造可以较快得到完整访问轨迹，但前段选择可能消耗重要时间窗口、留下不利的末状态，最终以昂贵机动赶上任务截止。仅增加时间罚或精修尾部，不能充分改变造成问题的早期决策。

用户提出：既然冠军总 ΔV 约 6 km/s，可在构造累计成本接近该水平时主动回溯，尝试其他机动；浅回溯不够，就回到更早的决策点。讨论认可的组织方向是：

> 用成本门槛判断固定前缀是否值得继续追加，用完整试走提前暴露昂贵后续，用逐级回溯改变早期决策，同时保留不同初轨和路线。

冠军约 6 km/s 是用户提供的竞争参考，尚无在本地模型中独立复核的对方轨迹；不是原问题下界或最优值。沿用已有 6.1 km/s 搜索目标，不另外建立一个含义模糊的“约 6”硬门槛。

## 2. 成本界的数学作用域

令 B=6.1 km/s。若一个前缀的初态及已执行控制保持不变，后续只追加真实脉冲，则

```text
J_full = J_fixed_prefix + J_suffix
J_suffix >= 0
```

因此，当 `J_fixed_prefix > B` 时，沿该固定前缀继续追加，不可能得到 `J_full <= B` 的解。应停止这种追加，转入撤销决策或修改已有控制。

边界必须明确：

- `J_fixed_prefix = B` 不等价于数学不可行，剩余目标可能通过零成本自然飞行访问。接近门槛可触发启发式回溯，但不能把严格大于与等于混同。
- 前缀控制必须真正固定，包括边界脉冲。若允许改变、删除或与新增同刻脉冲合并，规范化后的前缀成本可能下降；此时属于控制修复，不再适用原固定前缀成本界。
- 一次 B 调整开放了早期控制时，旧前缀成本不能作为调整后解的必然下界。必须重算控制、状态、覆盖和成本。
- 只剪除“保留此固定前缀继续追加”的分支，不宣称整个初轨、目标组合或轨迹族不可能达到 B。
- 原始 ΔV 与时间罚、倾角罚始终分开。成本阈值使用真实脉冲模长之和。

成本界是搜索政策，不新增赛题物理约束。超过 B 的轨迹可以保留为待重构提案，但不能成为合格工作解、elite 或正向成功奖励。

## 3. 完整试走：在真正超限之前发现问题

试走从候选的真实末时间、位置、速度和已访问集合出发，尝试访问全部剩余目标，最晚仍是任务第 10 天。它向前预测后果，回溯向后修改选择；二者互补。

对于重要候选，优先尝试完整补全，而不是只看后面两三个目标。短前瞻可用于初筛；完整试走帮助识别被不断推到后面的困难目标。

需要区分任务前瞻长度与计算预算：前者可一直到任务完成，后者决定尝试多少分支、多少补全策略及多少数值修正。不能把“完整试走”理解成对每个候选无限计算。

基本约定：

1. 用真实逐段状态传播后续，不把从同一入口分别到所有目标的最低腿成本相加，冒充完整后续成本。
2. 对少量有竞争力且走向不同的候选试走。可尝试偏重当前成本、访问窗口紧迫性、不同末状态和随机替代选择的补全方式；最终仍按完整原始 ΔV 比较。
3. 保存本轮生成的后续方案以继续探索；它不是固定访问计划，可改顺序、时刻、窗口、弧归属和控制。试走过程中若还需改变入口前的控制，应明确转入回溯/联合修复。
4. 试走给出便宜完整方案时，是一个具体可行候选的线索；通过独立验证后才报告完整物理成绩。固定前缀下的已验证补全成本可作为该受限子问题的可行上界，不能当下界。
5. 一次补全昂贵或失败，不证明不存在便宜补全。预算中断、引导失败、实际约束不通过、完整但昂贵分别记录。
6. 当前 H 是启发式估价，不是经证明的剩余成本下界；不得用 `J+H>B` 作永久安全剪枝。试走高成本也只能提高回溯优先级，不能直接证明该前缀不可达标。

## 4. 触发条件及其不同含义

| 情况 | 建议处理 | 能得出的结论 |
|---|---|---|
| 固定前缀原始成本严格超过 B | 停止沿其追加，撤销或修复已有控制 | 该固定前缀的纯追加无法达到 B |
| 接近 B，完整试走仍明显昂贵 | 提前安排替代补全与回溯 | 当前已尝试的走法不理想，不是不可行证明 |
| 剩余时间紧、便宜窗口错过或出现昂贵尾段 | 定位较早的相关决策，比较替代路线 | 当前局面值得重构，不把昂贵单脉冲直接判错 |
| 同一范围反复失败或生成重复候选 | 扩大回溯范围或轮换其他根/谱系 | 避免计算停留在同一有限候选集合 |
| 完整独立可行但高于 B | 保存物理结果，保留为重构线索 | 不进入合格池，不混入正向成功奖励 |

“接近”“明显昂贵”、连续失败次数、试走预算、回溯步长和路线配额尚未定量选定。本轮不把讨论举例固化为默认参数。

## 5. 回溯应如何改变决策

回溯是撤销离线规划中的选择，不是让飞行器物理返回。撤销单元不能永久绑定为“上一颗目标”，应能涵盖：

- 相遇窗口、访问顺序和同一目标的不同圈次；
- 等待时间、机动时刻及转移分支；
- 自然弧承担的零个、一个或多个访问；
- 过渡机动、脉冲增删合并及区段替换；
- 必要时更早控制和初始轨道。

先在当前范围试不同分支；有限尝试不理想时扩大范围。若已有证据指向更早错过的窗口，可直接回退到该决策之前，不必把每一级小范围穷尽。

跨过成本首次超限点不一定足够。例如前缀 5.7、下一脉冲 0.8 km/s，换掉该脉冲仍可能很贵，真正原因可能在更早的轨道面、相位或等待决策。回溯应允许继续前移，直到相关控制甚至初轨可以改变。

完全不变的前缀可按精确匹配复用。任何已改变控制之后的状态、成本和原覆盖都须重新计算，禁止接回旧后缀状态。以新完整任务成本判断净收益，不以最后一个脉冲变小或机动数减少替代。

## 6. 与束搜索和当前穿越点构造的关系

保留穿越点作为主要候选构造手段，用不同路线之间的轮换和每条路线内部的回溯，避免所有计算集中在单一初轨的深层子树。

需要记录已尝试的物理分支、尚未扩展的兄弟分支、回溯位置、失败类别和消耗预算，减少重复。连续变量只能有限采样；不能声称穷尽所有替代机动，或承诺回溯必然找到 6.1 km/s 解。

时间、末状态、覆盖集合和来源用于搜索多样性保留，不改最终单一 ΔV 目标。较早到达不自动支配较晚到达；同一累计成本也不代表同样的后续前景。

当前证据支持穿越点构造具有完整覆盖与重构降本能力，尚未证明其有限事件筛选、出发时刻和转移分支覆盖了冠军水平的路线。不能把本轮思路理解为“只需加一条阈值判断，其他机制已充分”。

## 7. 已有实验依据与不能推出的结论

详见 [最小历史回溯诊断](V4_BACKTRACK_DIAGNOSTIC_20260927.md)。对同一条历史完整轨迹，撤销最后 1/3/6 次机动后各重构 60 s：

| 方案 | 独立 J2 总 ΔV（km/s） |
|---|---:|
| 原解 | 20.535705413511 |
| 回退 1 次最好新替代 | 20.643131150451 |
| 回退 3 次最好新替代 | 20.431042346722 |
| 回退 6 次最好新替代 | 16.298106395837 |

均独立 35/35。6 次回退全任务节省 20.6353%，把 Target 28 的见证从第 9.9979 天前移至第 8.6207 天，Target 34 移到末尾；总代价变化涉及顺序、窗口和真实到达状态，未隔离各因素贡献。脉冲总数不变，不能归因为新增共享弧。

固定前 27 次机动已耗 13.191756020804 km/s，所以该诊断范围本身不可能达到 8 或 6.1 km/s。它支持更早回溯的价值，不证明阈值回溯已在冷启动搜索中奏效，也不证明回退越多必然越好。
