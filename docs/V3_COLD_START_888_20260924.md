## 输入与机制

- `initial_candidates={}`、`resume_file=''`；新工作池、恢复池、精英档案和信息素均从空状态开始。
- 不加载历史精英、轨迹、机动表、访问顺序、工作池或信息素。
- 使用原始目标的 J2 星历；它是问题输入，不是历史求解结果。新根包含随机初轨和目标几何引导初轨，均从当前目标数据重新生成。
- 全部现有机制启用。完整工作解的变异、昂贵连接重建和 SA 在本轮自行找到并独立验证完整解后才有可用输入；此前主要由束构造、前缀优化、完整恢复及困难目标重建推进。
- 总软预算 1440 s，随机种子 888，联合优化单次 60 s，补全与定向重建各 20 s，其余保持当前默认配置。这些是试验参数，未证明为最佳配置。
- 当前源码为 `free_maneuver_search_v3_7`。仅修正文档和实验配置，不修改搜索源码。已知的“计划变化但构造失败时可能在入恢复池前丢失”问题仍存在，不隐瞒或宣称已修复。

在 MATLAB 命令窗口执行。脚本不会读取旧精英或旧检查点；输出目录必须尚不存在。

```matlab
cd('D:\CTOC-14\simulation');
```

## 查看结果

运行结束后，或在另一个 MATLAB 会话查看已写入的检查点：

```matlab
cd('D:\CTOC-14\simulation');
folder = fullfile(pwd,'runs','v3','search','v3_cold_1440_seed888_01');
data = load(fullfile(folder,'checkpoint.mat'),'state');
S = data.state;
assert(isempty(S.config.initial_candidates) && isempty(S.config.resume_file));
fprintf('Cold start; seed %d; wall %.2f s; overrun %.2f s\n', ...
    S.config.seed,S.elapsed_s,S.budget_overrun_s);
fprintf('Joint calls %d; directed replans %d\n', ...
    numel(S.history),numel(S.replan_history));
if isempty(S.elite)
    fprintf('No independently verified complete solution yet.\n');
    if ~isempty(S.best_partial)
        fprintf('Best retained prefix coverage: %d/35 (not a complete result)\n', ...
            sum(S.best_partial.visited));
    end
else
    E = S.elite;
    fprintf('Independent passed %d; visits %d/35; DV %.12f km/s\n', ...
        E.verification.passed,E.verification.visit_count,E.verification.total_dv_km_s);
    fprintf('First complete archive %.2f s; best archive %.2f s; maneuvers %d\n', ...
        S.export_archive{1}.elapsed_s,E.elapsed_s,numel(E.schedule.maneuver_times_s));
end
if isfile(fullfile(folder,'summary.md'))
    disp(fileread(fullfile(folder,'summary.md')));
end
```

`best_partial` 仅为保留前缀的覆盖记录，不能作为完整任务成绩。没有 `elite.mat` 表示尚无独立合格完整解；不得调用 `initial_candidates{1}` 或计算相对旧精英的改善量。本轮首次完整解耗时以首次独立通过并归档时间计。1440 s 后归档的结果单独记录为软超时后成果。
