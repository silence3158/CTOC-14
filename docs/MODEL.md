## 2. 正式评分与本地优化目标

正式评分按严格优先级比较：先最大化不同目标的有效访问数 N，再在 N 相同时最小化 F2。

```text
F1 = N
F2 = total_dv / B
B  = 1 + 0.05 * (competition_end - submission_time)
                 / (competition_end - competition_start)
total_dv = sum(norm(delta_v[k]))
```

奖励系数中的时间是竞赛与提交验证时间，不是 2035 年轨道任务时间。同一提交时刻，最小化 F2 等价于最小化 total_dv。

本地正式问题固定要求 N = 35，在满足全部约束时最小化 total_dv。搜索可维护部分访问方案、失败候选与约束违反诊断以构造可行解，但不得把它们报告为已完成的全访问方案。不得用未经约定的加权和替代访问数优先规则，也不得以任务耗时作为第二优化目标或采用旧代码的 ΔV—耗时 Pareto 目标。

用户提供的参考成绩：2026-09-21，排行榜第一名 F2 = 16.653260。该数值未经本项目独立核验，单位和对应 B 尚未确认；只作为参考记录，不作为 ΔV 约束或已知最优值。结果应分别记录 total_dv 及其单位，以及可获得时的 B、F2 和提交验证时间。

## 3. 首版轨迹结构

1. 在固定初始历元建立可设计的近地轨道。
2. 允许先自然滑行 w0 秒。
3. 每段开始施加一次脉冲，在 J2 动力学下飞行到下一计划目标的位置。
4. 飞越后保留巡检飞行器的实际到达速度；下一段在同一事件时刻施加新的出发脉冲。
5. 第 35 次计划飞越后结束任务，不增加用于速度匹配或返航的末端脉冲。

这是用户接受的首版参数化，而非题目对全部合法轨迹的限制。首版有 35 个出发脉冲槽位，槽位脉冲可以为零。不单独优化段内额外机动或访问后的等待；也不据此声称覆盖原问题的全部轨迹或获得全局最优。未来改变轨迹结构应作为模型扩展记录。

初始自然滑行以动力学传播表达，不使用附件禁止的 ATK“保持段”。计划飞越可设置为 Lambert 段结束事件。途中非计划接近事件也应纳入实际访问计数。

## 4. 决策变量

### 4.1 初始轨道：6 个连续自由度

物理轨道由 a0、e0、i0、Omega0、omega0、nu0 确定，初始历元固定。建议优化编码为：

```text
q0 = [a0, ec0, es0, i0, Omega0, u0]
ec0 = e0 * cos(omega0)
es0 = e0 * sin(omega0)
u0  = omega0 + nu0
```

约束：

```text
RE + 590 <= a0 <= RE + 610       # km，含端点
ec0^2 + es0^2 < 1e-6            # 等价于 0 <= e0 < 0.001
0 <= i0 <= pi                  # rad
Omega0, u0 为周期角，规范化到 [0, 2*pi)
```

e0 > 0 时由 atan2(es0, ec0) 恢复 omega0，再由 u0 恢复 nu0。e0 = 0 时采用一致的规范（例如 omega0 = 0、nu0 = u0），避免使用未定义近地点。该编码缓解圆轨道退化，但未消除 i0 = 0 或 pi 时的节点退化，实现必须采取一致的轨道面表示或转换规范。

实现可使用等价且经过验证的非奇异编码，但必须保留相同的物理自由度与范围。600 km 圆轨道只能作为初始化或明确标注的受限实验，不能替代正式自由初轨模型。

### 4.2 访问顺序：一个排列

```text
pi = [pi[1], ..., pi[35]]
sorted(pi) = [1, ..., 35]
```

排列定义计划访问次序。最终有效访问数由整条轨迹与全部目标的接近事件确定；计划列表长度不等于实际访问数，重复接近同一目标仅计一次。

### 4.3 时间安排：36 个连续变量

```text
w0 >= 0
dt[k] > 0, k = 1,...,35
s[1] = t0 + w0
t[k] = t0 + w0 + sum(dt[1:k])
s[k] = t[k-1], k = 2,...,35
T = w0 + sum(dt)
T <= 864000 seconds
```

s[k] 为第 k 段出发时刻，t[k] 为其飞越时刻。T 为派生量，不额外引入独立总时长变量，也不强制 T = 864000。不设置服务停留变量，不沿用旧代码的单段 5—30 天边界。

数值求解需要的最短段时长、离散网格或搜索窗口必须作为可配置的算法限制单独记录，不能冒充赛题约束。优化器内部建议对变量缩放，物理接口仍使用本文单位。

### 4.4 转移分支：每段一个分支标识

```text
b = [b[1], ..., b[35]]
```

分支按实际 Lambert 求解器定义，可包含圈数、长短弧及多圈解族等。不得假定这些标志的任意组合都有效；J2 修正失败也应返回明确失败状态。

分支可以由内部求解器管理，不必与连续变量使用同一优化算法。必须保留比较不同分支的能力。逐段最小 ΔV 的贪心选择不保证全序列最优，因为不同分支具有不同到达速度。若剪枝、限制圈数或只保留部分分支，必须记录其配置与近似性质。

### 4.5 总体表示

```text
x = (q0, pi, w0, dt[1:35], b[1:35])
```

物理上共有 42 个连续变量、一个 35 元排列及 35 段分支选择。固定部分变量的实验必须标明，不得与完整模型混称。

## 5. 状态传递与轨迹评价

目标星历表示为 r_target[j](t)、v_target[j](t)。先将初始巡检状态传播至 s[1]，得到 r_start[1] 和 v_before[1]。

第 k 段在给定出发位置、目标到达位置、出发/到达时刻及分支后，通过考虑 J2 的边值求解获得：

```text
(v_dep[k], v_arr[k], trajectory[k], diagnostics[k])
    = solve_transfer(r_start[k], r_target[pi[k]](t[k]), s[k], t[k], b[k])

delta_v[k] = v_dep[k] - v_before[k]
```

对 k < 35：

```text
r_start[k+1]  = actual_end_position(trajectory[k])
v_before[k+1] = v_arr[k]
```

必须传递数值传播的真实末状态，不能把小的末端位置误差直接清零造成状态跳变。求解器应瞄准目标位置，并将残差控制在有效飞越阈值之内、留出验证余量。

飞越不约束到达速度等于目标速度。不得令 v_before[k+1] = v_target[pi[k]](t[k])，不得额外收取交会匹配脉冲。首版中脉冲矢量与到达速度由轨迹求解导出，不另作为与 Lambert 解重复的独立搜索变量。

候选评价至少返回：实际不同目标访问数、累计 ΔV、各段脉冲、实际出发/到达状态、时间安排、分支、末端误差、最低高度、约束违反/失败原因及验证层级。近似评价只能用于搜索筛选，不能代替正式动力学复核。

## 6. 固定输入、单位与动力学

- t0：UTC 2035-01-01 12:00:00。
- 任务截止：UTC 2035-01-11 12:00:00。
- 内部时间：相对 t0 的秒；转换至绝对时间时明确时间尺度与坐标转换约定。
- 内部单位：km、s、rad、km/s。
- CSV 的角度列为度；位置为 km，速度分量为 km/s，但模长列 `|v| (m/s)` 为 m/s，不得混用。
- 以与原始场景一致的笛卡尔位置速度作为目标传播输入。核验坐标系、历元、提取精度；不能仅根据列名臆定为某惯性系，也不能将其随意当作平均根数传播。
- CSV 的根数、周期与分类可用于理解、初始化及诊断，不是额外决策变量。
- 仅地球中心引力与 J2；引力场参数取自竞赛版 `AstroData/Earth/EGM96.grv`，核对系数归一化定义。
- 按题目处理地固系与惯性系变换。不得未验证就用旧参考代码的物理常数、J2 长期平均模型或其他摄动力替换正式动力学。

## 7. 硬约束与验证

1. 初始 a0 与 e0 满足第 4 节边界，e0 上界严格不等。
2. 全部机动、飞越和任务结束时刻位于正式时间窗口内。
3. 所有 35 颗目标均发生有效飞越：与巡检飞行器的距离不超过 1 km。每颗只计首次有效飞越。
4. 从初始历元到任务结束的整个飞行过程，高度不低于 200 km；必须包括初始滑行与各段内部，不能只检查端点。高度口径与官方验证器对齐。
5. 各段动力学和脉冲衔接成立，状态有限、求解成功。数值失败、NaN 或未到靶不得以有效低成本返回。

验证应区分近似搜索评价、本地正式动力学复核和竞赛版 ATK 验证。积分精度、事件定位精度及飞越安全余量是配置参数，不改变正式阈值。不能仅靠稀疏采样宣称满足全过程高度与飞越约束。
