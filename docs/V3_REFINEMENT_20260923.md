# V3 构造、初始化和联合恢复修订

日期：2026-09-23。承接 [用户短测分析](V3_USER_SHORT_TEST_20260923.md)，按束保留与预算、物理初猜、联合恢复三个步骤修改。MATLAB R2024a，nominal J2；未启动 ATK，未运行正式大批次。

## 1. 本次实现

1. `v3SelectBeam` 将约一半束槽位用于保留高覆盖前缀，另保留零新增访问槽位及几何多样性。剩余成本估计加入位置距离，避免仅靠速度接近偏爱远离目标的轨迹。估计不是可证明下界。
2. `v3Complete` 每次有独立墙钟预算，默认 8 秒，最多 35 步。补全后固定脉冲重放整个前缀，更新实际访问集合与见证；失败则回退原前缀。保存 `construction_history` 与 `best_partial`，后者不是独立验证精英。
3. `v3GuidedTransfer` 默认尝试 3 个目标/时间组合、每组合最多 3 个候选 Lambert 分支，使用阻尼 J2 STM 出发速度修正。二体深穿地轨迹先作为初猜过滤；最终仍检查 J2 轨迹高度。分支上限、重试次数和时长建议仅是搜索近似。
4. `v3ShootingProblem` 从原脉冲表传播初始化所有节点，不再把访问节点位置直接放到目标上。缺失见证使用当前轨迹最近接近时刻。既有有限节点/脉冲边界仍会截断超界初猜，因此这不保证每个受限初猜的连续性残差都接近零。
5. `v3Restore` 新增统一变量的阻尼 Gauss–Newton 可行性恢复：以正不等式残差与连续性等式残差构成最小二乘，使用 `lsqlin` 求带边界和线性时序约束的步，结合信赖步长、回溯和传播失败记录。初轨六变量、所有事件时刻、节点状态及脉冲同时参与。默认最多 25 次，分配联合预算的 65%。恢复残差不是 ΔV，不参加 SA 成本比较。
6. 只有约束违反达到 `10*constraint_tolerance` 后才开始同一变量空间的 `fmincon` ΔV 优化。恢复失败不能冒充燃料优化；固定脉冲原解保底与新解改进分开记录。
7. 未完成前缀每 3 次迭代最多用 3 秒对已有见证做联合整理，避免把预算全部花在凭空补足缺失目标的 NLP 上。该调用记为 `prefix_*`，不是完整 35 目标求解；完整候选仍进入全任务联合求解。前缀没有永久锁定，完整任务的 SA、信息素奖励和独立导出门槛没有放宽。

启动时实际探测 `fmincon` 和 `lsqlin`；二者已在本机成功调用。实现签名增加 `checkArc.m` 依赖。旧检查点不能在本次实现上恢复，须使用新输出标签。

## 2. 验证

`test_v3_search` 共 24 项通过。新增四项覆盖：高覆盖前缀不被廉价滑行全部挤出、未超界初猜节点连续性、相位偏移合成案例的真实失配恢复、补全预算不受此前全局累计耗时误截断。

单独的合成相位偏移检查中，恢复平方残差由约 3.98e-4 降至 4.33e-13，实际重放恢复 35 个合成共轨目标。该结果只验证算法环节，不是竞赛数据成绩。真实目标上的联合收敛仍未得到证明。

## 4. 结论和下一步

这轮修改改善了搜索层的完整候选构造，但没有形成可用的 V3 竞赛解，也没有证据证明总 ΔV 改善。独立出口正确拒绝了不稳定或不合格候选，没有生成 `elite.mat`。251–281 km/s 远高于用户给出的约 6 km/s 参考，不应通过增加同类种子批次掩盖问题。

下一轮应先定位搜索重放与独立重放的轨迹/见证分歧，检查分段传播和超界节点截断对初猜的影响，再调整连接成本与完整候选燃料质量。只有真实数据恢复能稳定进入 ΔV 优化后，才有充分理由扩大正式批次。当前尚未确定分歧的唯一原因。
