# V3 搜索流程修复：完整恢复、结构构造与失败调度

日期：2026-09-23。对应用户静态审核后确认的三项修复。正式模型仍为 MODEL_V3.md，不改变初轨、自由机动、35 个目标、1 km 飞越、200 km 高度或 10 天条件。未启动 ATK，未执行正式长预算批次。

## 1. 完整任务恢复语义

恢复池现在保存记录，而不是只有脉冲表：

```text
schedule    实际初轨、脉冲表、访问证据与可选访问计划
target_ids  本次恢复必须满足的目标集合
parent      原完整可行工作解及其 J，供恢复后 SA 比较
stalls      连续没有物理恢复进展的次数
```

完整候选的 target_ids 始终为 1:35。未飞到的目标可以没有有效 witness，但不因此退出恢复约束。部分构造前缀可以使用其原有的部分目标集合；这种调用仍标为 prefix_*，不冒充完整任务求解。恢复池取出候选后继续恢复，不先再次随机变异。

不可行候选比较固定脉冲实际重放的目标距离超差范数，不用较低 ΔV 或当前访问数覆盖恢复进展。当前实现先要求重放高度通过，才赋予有限的距离恢复指标；这不是可行成本，也不是新增评分目标。已满足活动目标集合的可行输入仍按真实 ΔV 保底。默认 recovery_stall_limit=3，只限制连续没有进展的重试，记录为搜索近似；有恢复进展时清零。

完整恢复失败的候选不再作为缺少目标的末端前缀送入束。成功候选继续固定原脉冲独立验证；有父工作解的恢复候选使用该父解的真实 J 进行 SA 比较，不丢失父解后自动接受。

## 2. 结构候选与访问计划

新增 v3FitVisitArcs，替换工作池变异中连接原轨迹端点的构造方式：

1. 按提案的初轨、机动时刻和访问时刻构造自然弧。
2. 每条有访问的弧同时拟合该弧内全部计划目标，使用 J2 状态转移矩阵和阻尼最小二乘修正出发速度。
3. 无访问弧保留提案脉冲并实际传播；每条弧都将实际到达位置和速度传到下一弧。
4. 这些固定时序的逐弧拟合只是初猜构造。拟合不能同时满足全部访问时仍显式记录残差，随后由原统一多重打靶恢复释放初轨、机动时刻/矢量、访问时刻及任务结束时间。

构造器不再强制回到旧轨迹的下一机动位置。没有增加节点瞬移、目标速度重置或额外交会脉冲。弧内目标中心拟合是初猜策略，不改变最终 1 km 球形条件。构造通过仅表示完成可传播提案，不表示高度或全部访问已经验证；报告中的 full_feasibility_verified 固定为 false，完整验收仍由 v3Verify 执行。

删除和合并在小尺度下也实际减少机动，取消以缩小脉冲冒充删除。插入机动时，若存在前序机动，同时扰动其脉冲以改变进入新机动点的真实状态。访问重分配不再被替换为初轨变异，采用相邻或广域访问时刻交换。还修复了原入口的 nargin<7 错误：该函数只有六个参数，原代码导致显式算子参数被忽略。

visit_plan_times_s 保存待实现的访问安排，与实际扫描发现的 witness_times_s 分开。多重打靶使用计划事件初始化和排序，局部求解仍可移动其时刻。v3JointReplay 同时记录真实覆盖与计划时刻误差，防止在旧时刻飞过目标就冒充完成新的访问安排。计划误差使用名义目标缓存作恢复诊断；最终实际飞越仍使用独立目标积分认证。成功进入工作池后去掉临时计划字段，保存实际访问见证。

v3MutationDifference 检查初始笛卡尔状态、有效脉冲数、机动时刻及脉冲矢量差异。默认位置、速度/脉冲、时间阈值为 0.001 km、1e-6 km/s、0.001 s，是可配置数值去重近似。仅更改访问标签不构成物理新轨迹；访问重排提案可以先进入联合恢复，但返回原物理轨迹时不会计为新结构接受。这不是完整轨迹族聚类或多样性管理。

## 3. 失败调度

v3BeginAttempt 在进入候选操作前记录 source_history。来源轮转按尝试数推进，连接失败、前缀暂缓、重复输入和求解失败不会占住同一个来源名额。history 继续只保存已完成联合调用，二者不混用。

新根保护按各群自己的 colony_iterations 计数，消除 colony_count=2 与 protected_root_every=2 周期重合导致第一群永远只取新根的问题。construction_history 记录 colony、colony_iteration 和 protected_root，可检查每群实际扩展机会。
