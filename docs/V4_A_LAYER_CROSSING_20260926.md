## 3. 设计

### A1 穿越事件表（`events.m`）

从节点末端（从最后一个真实脉冲起积分，与重放同一流）弹道传播窗口 W（默认 48 h）。以密切角动量 ĥ(t) 求剩余目标 ĥ(t)·r_j(t)=0 的时刻；与巡检器轨道面夹角 <2° 的目标改求“巡检器密切圆锥在目标方向上的半径 = 目标半径”。事件只是提案，不是访问证据。

每个事件附带一个排序用 ΔV 估计：在该方向上把远/近地点改到目标半径所需的切向增量，加上面外角乘速度的改面代价。它忽略相位，不是下界。

### A2 穿越点定时转移（`expand.m` 主干）

对每个事件，出发时刻取当前时刻及窗口内若干点（近地点、远地点、均匀等待），用现有多圈 Lambert 求 x(τ)→r_j(θ)。先按 A1 估计取前 K 个事件，再按 Lambert ΔV 与倾角罚排序，按规格式 (30) 的概率选子代（保留 ε 随机探索）；子代经 `v3GuidedTransfer` J2 修正和真实重放。旧的任意时刻 Lambert 枚举保留小比例作为多样性来源。

### A3 共享弧（机会性升级）

只作用于最后一段弧：新子代生成后，在其新弧上寻找其他目标的近距离机会，交给 B 以“一次脉冲 + 两个见证”联合求解；焦点在最后一段，没有被动后缀。

### A4 分层束（`selectBeam.m`、`search.m`）

按访问数 k 分层，同层以 f = J + H + P 比较：J 为已花原始 ΔV；H 为 A1 估计的剩余目标代价（截尾平均 × 剩余数 × 折扣，启发式）；P 为时间超支罚，已用时间超过 T_max·k/35 加松弛才计。每层保留代表，同层内按末状态轨道面和形状保持差异。新根在自己的层竞争。

## 4. 检验计划

- T1：同一冷启动节点，穿越点候选的单步 ΔV 分布对比现有枚举。
- T2：束宽 1 的贪心链能否走完 35 目标，成本多少（诊断，不计成绩）。
- T3：seed 888、300 秒冷启动，独立 35/35 与原始 ΔV；对照 V3 冷启动 18.34 km/s。

不承诺达到 8 km/s。
