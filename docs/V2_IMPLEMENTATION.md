# V2 首轮实施范围与复现实验

日期：2026-09-21。模型依据：[MODEL_V2.md](MODEL_V2.md)。本文件记录实际实现范围，不将设计中的后续能力视为已完成。

后续版本说明：本文保留首轮小批次实施记录。用户随后要求的全局束搜索、自由初轨联合优化及通用多目标片段，已单独实现和试验，当前扩展范围及限制见 [V2_ADVANCED_ALGORITHMS.md](V2_ADVANCED_ALGORITHMS.md)。下文“未实现”描述适用于首轮历史版本。

## 已实现的闭环

- `importV1Candidate`：保留原初轨、实际脉冲及访问时刻，转换为 `fragment_schedule_v2` 固定脉冲时间表。任务结束取不早于最后访问的原记录时间，处理原累加顺序造成的约 1e-10 s 差异，不修改物理状态。
- `propagateSchedule`：按显式时间表传播，访问不触发状态重置，支持无脉冲弧和一弧多访问。可选择独立 ode113 连续积分，同时独立积分全部目标；在各目标访问见证时刻检查真实距离，以有限弧解析极值检查全过程高度。
- `scanEncounters`：时间网格加局部距离极小值优化，产生候选。只用于发现机会，不证明不存在其他接近事件。
- `shootFragments` / `refineFragment`：先向目标 A 作 Lambert 引导试射，20% 的试射再扰动脉冲，沿自然延拓弧发现 B。通过实际无中间脉冲的六变量打靶微调得到 S2，检查两次真实飞越和完整片段高度。
- `rebuildSchedule`：真实状态连续传递；对改动后的所有后续目标重新计算转移脉冲，避免沿用失效后缀成本。已有参考分支用于连续性偏好，分支均需满足高度。
- `repairFragmentWindow`：S1 的入口滑行与到达时刻局部 SQP，目标是重算后的完整任务总 ΔV。
- `runFragmentSearch`：保留完整基线，交替试射 S2 与优化 S1，只接受完整筛选成本下降者；记录每次候选和优化器诊断；按源码/数据/配置签名检查断点恢复。
- `run_fragment_pilot`：独立种子、最多四进程、内层串行、无并行工具箱时同算法串行；搜索预算与最终独立复核分开计时。

## 当前明确的搜索限制

本次是 V2 局部修复 pilot，不是 MODEL_V2 的全部算法完成：

- 固定已有最好精英的初始轨道，初轨 6 自由度的全局探索未在本轮开放。
- S2 从相邻访问区间选入口，在接下来最多 4 个目标中寻找第二个目标；可重排这一区段。没有全剩余目标束搜索。
- 单次试射的时间和脉冲窗口见代码及保存配置；起步两圈 Lambert 上限为计算近似。
- 保留 S1 和 S2；尚无 D3、额外脉冲插入、从零构造束搜索、全变量联合精修。
- 独立验证为每个目标提供真实距离 <=1 km 的访问见证，足以证明全部 35 目标已访问；尚未实现全区间所有事件的穷尽定位或最早进入 1 km 球时刻报告。不能称为“完整最近接近事件目录”。
- 小批次仅和已知 V1 精英数值作基线比较，尚未运行同预算 V1 继续搜索及 S1-only 消融，不能据此声称普遍优于旧算法。

S2 局部通过、完整任务回接成功、被接受为更低成本候选、最终独立复核通过分别计数。只有最终独立复核通过的完整任务写入本轮 `elite.mat`。

## 验证与入口

环境已实际核验 MATLAB R2024a、Optimization Toolbox 24.1、Parallel Computing Toolbox 24.1；已读取本机 `optimoptions('lsqnonlin')` 与 `optimoptions('fmincon')` 后配置求解器。

`tests/TestFragments.m` 包含单脉冲双目标独立传播、删错脉冲拒绝、重复访问去重、无脉冲访问、非法时间/初轨、段内低高度、近接近扫描和打靶微调测试。

```matlab
addpath('scripts');
check_fragment_implementation;
run_fragment_pilot(60,1,'smoke_20260921');
run_fragment_pilot(120,4,'fragment120_20260921',1); % 仅 S2 片段修复
run_fragment_pilot(480,4,'pilot8min_20260921');    % S1/S2 混合
report_fragment_pilot('pilot8min_20260921');
```

运行目录：`runs/fragments/<label>`。不同配置必须使用新 label；相同配置可读取每任务检查点续跑。每 30 秒保存一次检查点，任务目录的 STOP 文件在迭代边界停止搜索。墙钟停止是软预算，最后一次算子和写盘可能略超时。随机状态、全部配置与诊断保存于 MAT；同一种子在墙钟预算下不保证不同机器完成相同迭代数。

源码目录新增文件会改变全包签名；旧 V1 检查点可能因签名不一致拒绝续跑，这是兼容性保护，不修改旧检查点以绕过。旧精英文件仍可作为固定结果加载和转换。

结果报告另见 [V2_PILOT_RESULTS_20260921.md](V2_PILOT_RESULTS_20260921.md)（实验结束后归档）。
