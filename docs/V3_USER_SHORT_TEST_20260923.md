## 代码与结果共同支持的诊断

1. **完整初猜质量不足。** `v3ShootingProblem` 给未知目标按目标编号均匀分配时间，并将辅助节点位置初始化为目标位置，但保留原传播速度。这只使节点的目标距离看起来小，不能使相邻节点动力学连续。联合优化器需要从非常不连续的初值恢复全部35个目标；15次迭代/12秒通常未取得有意义的恢复。
2. **构造方向存在偏差。** `v3SelectBeam` 按已耗成本加启发式估价排序，保留零增访额度，但没有对覆盖进度建立对应的保留额度。启发式主要使用速度差，缺少位置、可连接性与剩余时间约束信息。最终群1八条路径中七条零访问；其中两条地心半径约101万与126万km仍被保留。远距离过渡不是非法模型状态，但这里缺乏后续回访潜力证据。
3. **补全时间门槛是全局截止。** `v3Search` 中 `toc(clock)>=0.6*budget_s` 意味着本次72秒后所有后续迭代跳过快速补全，不是每次给补全60%的独立预算。之后仍会把不完整前缀送入全35目标问题。
4. **目前恢复主要依靠直接成本 NLP。** 同一个 fmincon 以 ΔV 为目标满足约束，没有单独实现针对大缺陷的联合可行性恢复阶段。需要在不冻结初轨、时序或结构的前提下改善恢复；不能将有限罚值当作真实可行成本。
5. **自适应机制尚未获得输入。** 工作池为空，因此SA没有实际比较；完整独立收益强化也未触发，信息素表为空。本次不能评价SA或蚁群学习的收益。

## 建议的改进顺序

1. 调整束保留：分别保留覆盖进展、低成本与有后续连接潜力的过渡候选；仍允许零访问/远距离/多圈轨迹，不添加模型硬限制。
2. 改善目标引导与补全：对失败几何尝试替代时长/分支，构造动力学较一致的整任务初猜；将补全改为每次调用自己的预算，避免72秒后永久停用。
3. 在相同全变量问题内增加显式可行性恢复，再压缩真实 ΔV。联合优化前记录节点位置/速度缺陷、已确认访问数和拓扑容量；避免对明显不完整、少脉冲候选盲目施加全35目标硬恢复。
4. 修复后再做一次同seed、同120秒预算比较，重点看构造覆盖、最大动力学缺陷下降、恢复成功率和首次35/35出现时间。产生完整可行工作解后，才扩大种子批次并比较总ΔV及SA/信息素作用。

可同时加入一条历史V2实际脉冲表作J2恢复诊断，保持其全部变量开放，与从零构造并行；它不能替代广域初轨搜索，也不能继承二体可行性。

本次仅分析、记录，没有修改搜索算法或启动正式批次。
